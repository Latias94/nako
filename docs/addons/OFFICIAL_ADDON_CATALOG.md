# Official Addon Catalog

This generated catalog is the operator-visible inventory for official Nako Addons. It is derived from `crates/nako-official-addon-catalog` manifest and install descriptor builders, then verified by crate tests.

Catalog scope is discovery, compatibility, install references, and smoke status. It is not an Addon Manager: Nako still does not install, update, start, stop, remove, log, or supervise Addon Sidecar processes.

- Catalog artifact: `docs/addons/OFFICIAL_ADDON_CATALOG.md`
- Compatible Nako version range: `>=0.1.0-alpha.2 <0.2.0`
- Excluded helper surfaces: `browser-worker` is a browser-render helper, not an Addon catalog entry.
