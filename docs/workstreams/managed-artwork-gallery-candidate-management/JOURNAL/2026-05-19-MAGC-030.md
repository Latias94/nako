# MAGC-030 Session Notes

Date: 2026-05-19

## Scope

Implemented guarded Admin selection management from the gallery context.

## Shipped Shape

- `POST /admin/v1/items/{item_id}/artwork/{kind}/select`
- Request body:
  - `artifact_id`
- Supported path kinds:
  - `poster`
  - `backdrop`
  - `logo`
  - `thumbnail`
  - `banner`

## Behavior

- The command is idempotent when the artifact is already selected.
- Selecting another eligible artifact replaces the slot while preserving the
  Selected Artwork public ID.
- The repository guard rejects artifacts that do not match the requested item
  and kind.
- The command does not delete, unpublish, re-ingest, repair, or mutate artifact
  files.
