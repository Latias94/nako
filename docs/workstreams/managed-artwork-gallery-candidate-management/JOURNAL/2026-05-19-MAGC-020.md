# MAGC-020 Session Notes

Date: 2026-05-19

## Scope

Implemented the first redacted Admin item artwork gallery read model.

## Shipped Shape

- `GET /admin/v1/items/{item_id}/artwork?limit=50&offset=0`
- Core/db snapshot separates:
  - Artwork Candidates;
  - Managed Artwork Artifacts;
  - Selected Artwork.
- Admin DTOs return safe IDs, statuses, dimensions, media type, byte length,
  selected flags, selected counts, and Public Client image references for
  selected artwork.

## Redaction Notes

- Gallery snapshot records do not carry raw candidate `source_uri`, artifact
  `storage_uri`, or content hash values.
- Admin ingest artifact summaries now expose `has_content_hash` instead of
  content hash values.
- Public image refs remain Selected Artwork based.
