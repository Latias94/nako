# ACFH-030 — TokenVault Migration

Date: 2026-05-22
Status: DONE

## Summary

The default Android TokenVault no longer depends on deprecated AndroidX Security
`EncryptedSharedPreferences`. It now stores encrypted token records with Android
Keystore AES-GCM behind the existing `TokenVault` interface.

## Evidence

- `apps/android/app/src/main/java/dev/taru/android/connection/AndroidSecureTokenVault.kt`
- `apps/android/app/src/test/java/dev/taru/android/connection/SharedPreferencesTokenVaultTest.kt`
- Deprecated crypto grep: PASS.
- Focused Android JVM gate: PASS.

## Notes

A no-deprecated `TokenVaultMigrationSource` seam preserves read-through
migration behavior for compatible legacy providers without keeping the
deprecated dependency in the default app build.
