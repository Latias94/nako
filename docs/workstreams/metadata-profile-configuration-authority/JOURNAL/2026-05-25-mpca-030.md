# MPCA-030 Journal

Date: 2026-05-25

## Summary

Closed the Metadata Profile Configuration Authority lane.

## Result

The target source-of-truth behavior is implemented:

- preset-generated profiles use `metadata_profile_source = preset`;
- explicit TOML profile overrides use `metadata_profile_source = configured`;
- Admin API updates use `metadata_profile_source = admin`;
- startup reconciliation preserves Admin-owned profiles when TOML only supplies
  preset defaults;
- explicit TOML overrides remain authoritative.
