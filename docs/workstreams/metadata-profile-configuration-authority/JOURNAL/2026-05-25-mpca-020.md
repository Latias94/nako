# MPCA-020 Journal

Date: 2026-05-25

## Summary

Implemented restart-proof Metadata Profile authority for Admin-updated
profiles.

## Changes

- Added internal `MetadataProfileSource` to `LibraryOptions` with
  serde-defaulted `preset` for existing persisted JSON.
- Marked TOML `metadata.library_profiles` overrides as `configured`.
- Marked Admin API profile updates as `admin`.
- Updated configured-library reconciliation to preserve persisted Admin-owned
  profiles when desired config only has preset defaults.
- Added startup tests for Admin profile restart preservation and explicit TOML
  override replacement.

## Follow-Ons

- Admin Web V2 should explain whether the current profile is preset,
  configured, or Admin-owned.
- A future config export/import command can make Admin updates portable into
  TOML-managed deployments.
- Field-specific patch commands may make profile editing safer for UI forms.
