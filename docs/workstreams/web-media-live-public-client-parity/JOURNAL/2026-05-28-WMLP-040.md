## Concern

Heartbeat/session identity is not wired because `BrowserPlaybackTicketResponse`
does not expose a playback session id. The backend may emit session ids through
stream response headers, but a web video element cannot reliably surface that
identity to this data source. This needs a follow-on Public Client contract
before browser heartbeat can be made truthful.
