# Media Server Architecture Progress Map

Status: Closed
Last updated: 2026-05-29

Documentation lane for making Nako's long-term Jellyfin/Plex-class media
server target navigable. The lane keeps the top-level architecture map concise,
adds architecture deep dives and a workstream link index, records the
HLS/media-engine boundary in ADR 0052, and records the application
control-plane boundary in ADR 0053.
