# CRA-050 Admin Web Repair UI

Date: 2026-05-25

## Summary

Added the route-owned Admin Web repair context for the first Catalog Governance
repair action.

## Changes

- Added queue-to-repair navigation from `/catalog/governance`.
- Added `/catalog/governance/{item_id}` as the repair context route.
- Added Provider Mapping selection through URL-backed `mapping_id`.
- Added URL-backed `decision=accept|reject` state.
- Rendered safe Media Item, Provider Mapping, review-plan, readiness, and
  mutation boundary summaries.
- Required a prepare step before the confirmed mutation button is shown.
- Rendered mutation success and unavailable-action failure states.
- Kept raw Local Inference evidence, Source Locators, local paths, provider raw
  bodies, provider URLs, NFO XML/paths, tokens, and arbitrary raw payload fields
  out of route rendering.
