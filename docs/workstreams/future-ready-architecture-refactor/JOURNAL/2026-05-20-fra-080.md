# FRA-080 — Local Inference Engine

Date: 2026-05-20
Status: Complete.

## Intent

Separate Media Source discovery from local interpretation. Scanning should
discover storage facts. Local Inference should explain those facts as
provisional media hierarchy, evidence, and source state. Persistence should
commit the planned result.

## Changes

- Removed `ParsedName` from `DiscoveredMediaSource`.
- Removed name parsing from `VfsLibraryScanner`; scanning now records VFS media
  source facts only:
  - URI;
  - file name;
  - size;
  - modified timestamp;
  - ETag;
  - fingerprint;
  - stale-cache marker.
- Deepened `crates/nako-library/src/local_inference.rs` around
  `LocalInferenceEngine`.
- `LocalInferenceEngine` now:
  - parses discovered source paths with `nako-naming`;
  - builds `LocalInferenceEvidence`;
  - builds `SourceState`;
  - builds a source-shaped `MediaSource`;
  - builds a primary provisional `MediaItem`;
  - plans required provisional hierarchy ancestors.
- `LibraryIndexService` now:
  - calls the engine for a plan;
  - preserves confirmed canonical metadata on rescan;
  - resolves or creates planned provisional ancestors through repository
    lookups;
  - commits source state, media source, evidence, library item states, and
    search projection through the existing `commit_library_scan_source`
    persistence unit.

## What This Proves

- VFS scanning no longer embeds Local Inference output.
- Local Inference owns file-name interpretation and provisional hierarchy
  planning.
- Indexing still owns repository lookups and commit orchestration rather than
  hiding persistence inside inference.
- Existing local inference behavior for movie, episode hierarchy, unknown
  source, confirmed metadata preservation, source tombstoning, and scan failure
  handling remains covered by the `nako-library` package tests.

## What It Does Not Claim

- Local Inference does not yet use NFO sidecars, nearby files, or media probe
  facts as additional evidence sources.
- Local Inference is still inside `nako-library`; it has not been split into a
  separate crate.
- Anime-specific season/special/absolute-numbering heuristics remain future
  enhancements.
- Search semantics remain FRA-100.
