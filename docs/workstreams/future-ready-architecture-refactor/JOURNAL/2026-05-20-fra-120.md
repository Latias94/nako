# 2026-05-20 — FRA-120 Generated/Frontend Repository Hygiene

## Task

Clean generated/frontend repository hygiene: ignore build outputs, logs,
Playwright artifacts, TypeScript build-info files, and dependency folders while
keeping generated contracts reproducible by commands.

## Findings

The repository already ignored root `node_modules` and the admin-web app
already had local ignores for `dist`, Vite server logs, Playwright CLI logs,
and `*.tsbuildinfo`. The observed local artifacts matched that intent:
`apps/admin-web/dist`, `.playwright-cli`, `.vite-server.*.log`,
`tsconfig.tsbuildinfo`, and `node_modules` were ignored.

Two things were still too implicit:

- common frontend artifact categories such as coverage reports, test results,
  Playwright reports, Vite caches, and package-manager debug logs were not
  consistently covered at root/package level;
- the Admin API generated contract had an emit example and a sync test, but
  `apps/admin-web` did not expose a package-local generation command or include
  it in `npm run verify`.

## Changes

- Expanded root `.gitignore` for frontend dependency/build output, coverage,
  Playwright/test reports, TypeScript/Vite artifacts, and package-manager debug
  logs.
- Expanded `apps/admin-web/.gitignore` with the app-local artifact set.
- Added `sdk/typescript/.gitignore` for package-local generated build and
  debug artifacts.
- Added `npm run generate:admin-api --prefix apps/admin-web`.
- Updated `apps/admin-web` `verify` so it regenerates the Admin API contract
  before TypeScript check, tests, and build.
- Documented the Admin API contract generation command in the admin-web README.

## Validation

- `git check-ignore -v ...` proved admin-web build/log/Playwright/tsbuildinfo
  artifacts and SDK tsbuildinfo artifacts match the expected ignore rules.
- `npm run generate:admin-api --prefix apps/admin-web` passed and left
  `apps/admin-web/src/adminApi/generated/contract.ts` textually unchanged.
- `npm run verify --prefix apps/admin-web` passed: Admin API generation,
  TypeScript check, 3 Vitest files / 9 tests, and Vite build all completed.
- `npm run verify --prefix sdk/typescript` passed: Public Client SDK generation
  and TypeScript check completed; `sdk/typescript/src/index.ts` was textually
  unchanged.
- `cargo fmt --all --check` passed.
- `git diff --check` passed with CRLF warnings only.

## Follow-up

FRA-130 should perform the deletion sweep. Because the working tree includes
large earlier refactor changes, do not delete ignored local artifacts or tracked
generated files without explicit proof and user approval.
