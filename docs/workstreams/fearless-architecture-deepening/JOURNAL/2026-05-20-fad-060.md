# FAD-060 — Hardware Diagnostics

Date: 2026-05-20

## Scope

Deepened hardware acceleration diagnostics so encoder discovery, device
initialization, and optional smoke probes are represented separately and can be
reported through safe Admin API summaries.

## Changes

- Replaced the single hardware capability evidence field with:
  - `HardwareEncoderDiscovery`;
  - `HardwareDeviceInitialization`;
  - `HardwareSmokeProbe`.
- Added device initialization detector seams and static fake results for tests.
- Kept normal detection unprivileged: FFmpeg encoder discovery still reads
  `ffmpeg -encoders`; device initialization and smoke probes default to safe
  operator guidance unless explicitly provided.
- Made explicit device initialization failure and smoke-probe failure mark the
  accelerator unavailable.
- Updated Admin playback runtime diagnostics, Admin TypeScript contract,
  admin-web mock data, and HTTP API docs.
