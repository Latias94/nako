# FAD-050 — Playback And Transcode Identity

Date: 2026-05-20

## Scope

Defined and tested stable playback/transcode request identity before widening
HLS reuse, subtitles, HDR/SDR variants, or adaptive ladders.

## Changes

- Added `PlaybackProfileIdentity` to `nako-streaming`.
- Added `TranscodeSourceIdentity` and `TranscodeRequestIdentity` to
  `nako-transcode`.
- Bound `TranscodeProfileIdentity` to Media Source revision facts before using
  it for persisted request keys and staging slugs.
- Updated remux and HLS app services and tests to use request identity.
- Added source-revision and selected-hardware identity coverage.
