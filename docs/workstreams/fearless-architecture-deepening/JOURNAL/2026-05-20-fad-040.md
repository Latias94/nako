# FAD-040 — Library Ingestion Workflow Depth

Date: 2026-05-20

## Scope

Deepened the Library ingestion caller boundary so `LibraryIndexService` no
longer depends on a broad repository trait alias to coordinate scanner output,
Local Inference, Source State, Library Item State, Local Inference Evidence,
ingestion failures, Search Projection, and scan-source persistence.

## Changes

- Added `crates/nako-library/src/ingestion.rs`.
- Introduced `LibraryIngestionWorkflow` and workflow commit/request summaries
  for scan failures, directory observations, source observations, and
  missing-source tombstoning.
- Deleted the caller-facing `LibraryIndexRepository` alias.
- Moved local-inference/source/search/failure composition out of
  `LibraryIndexService` and into the workflow Adapter.
- Kept `LibraryScanner`, `LocalInferenceEngine`, and
  `commit_library_scan_source` as separate Modules/seams.
- Added a fake workflow test proving the service can index without implementing
  low-level repository traits.
