# FAD-070 — Search Semantics

Date: 2026-05-20

## Scope

Added measured search semantics and projection-version discipline before AI or
vector search broadens Taru search behavior.

## Changes

- Added a shared `taru-search` evaluation harness for title, alias, body, facet,
  exact Browse Facet, pagination, and CJK-friendly compact matching semantics.
- Added projection-version freshness helpers on `SearchDocument` and
  `SearchEvaluationDocument`.
- Refactored SQLite and PostgreSQL `SearchIndex` adapters to load rows and
  delegate semantics to `taru-search`, removing duplicated backend scoring.
- Updated Catalog hydration to project accepted Provider Subject titles/keys
  into Search Projection aliases/body/facets.
- Widened `NfoImportRepository` to include `ProviderMappingRepository` because
  NFO catalog projection planning now uses Provider Mapping context.
