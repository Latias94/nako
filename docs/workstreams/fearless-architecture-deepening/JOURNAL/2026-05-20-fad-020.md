# 2026-05-20 — FAD-020 Addon Side Effect Module Depth

Status: DONE.

## What Changed

Split `crates/nako-server/src/app/addons.rs` so `AddonAppService` is no longer
the single home for Addon Principal resolution, Addon Side Effect intake, apply
routing, and each concrete apply behavior.

New Modules:

- `app/addons/principal.rs`
- `app/addons/intake.rs`
- `app/addons/side_effect_apply.rs`
- `app/addons/metadata_write.rs`
- `app/addons/library_file_write.rs`
- `app/addons/artwork_write.rs`
- `app/addons/target.rs`

The split is behavior-preserving. It prepares FAD-030 by putting current Addon
metadata write behavior behind a dedicated Adapter before changing commit
semantics.
