# Admin Web Addon Credential and Grant Onboarding

Status: Completed
Opened: 2026-05-22
Closed: 2026-05-22
Owner: codex

This workstream completes the safe Admin Web onboarding bridge between a
registered **Addon Sidecar** and an enabled runtime Addon: one-time Addon Token
issuance, token rotate/revoke, accepted Addon Grant replacement, and an enable
readiness checklist. It preserves the established boundary that Nako registers,
authorizes, and calls sidecars but does not install, start, stop, update,
remove, log, or supervise their processes.
