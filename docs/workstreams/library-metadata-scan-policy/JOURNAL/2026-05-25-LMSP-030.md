# 2026-05-25 - LMSP-030

Implemented scan-time NFO Import.

- Extended `ScanCommandOutput` with `metadata`.
- Added `LibraryScanMetadataSummary` with an optional NFO import summary.
- Library scan now evaluates `MetadataProfile::scan_acquisition_plan` after
  index/probe.
- When `local_nfo_import` is enabled, scan reuses `NfoService` and the existing
  NFO import path instead of duplicating sidecar parsing or merge logic.
- Public Client DTO/OpenAPI now include `MetadataScanPolicyDto`.
- Added tests for enabled and disabled scan-time NFO import.
