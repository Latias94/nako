# Managed Import Staging MIS-050/MIS-060 Closeout — 2026-05-21

## Summary

Closed Managed Import Staging as a non-mutating staging and promotion-preview
lane. Actual promotion apply is split to
`docs/workstreams/link-apply-and-import-promotion`.

## Decision

Promotion apply must not live inside the staging lane because it is the first
operation family that can mutate Media Library roots and catalog state.

Required follow-on boundaries:

- operator confirmation;
- plan revalidation before mutation;
- durable idempotent apply/audit records;
- VFS-only storage mutation;
- rollback and cleanup after partial failure;
- catalog consistency before a Media Source is promoted;
- explicit NFO import/export boundaries.

- `WORKSTREAM.json` routes continuation to
  `link-apply-and-import-promotion LAIP-020`.
- Parent umbrella and workstream index are updated to point at the follow-on.
