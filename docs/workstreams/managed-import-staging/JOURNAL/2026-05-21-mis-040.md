# 2026-05-21 — MIS-040 Promotion Plan Preview

## Scope

Added a non-mutating Managed Import promotion preview model and app service
method.

## Behavior

- Builds the target Source Locator from the target Media Library root and
  intended locator.
- Reports future copy/move apply options without mutating storage.
- Calls VFS `plan_link` for hardlink/symlink dry-run status.
- Emits duplicate hints from fingerprint/size evidence against existing Media
  Sources in the target library.
- Reports NFO sidecar authority hints from library local metadata policy and
  sidecar existence.
- Reports provider identity review hints from the target library metadata
  profile and Managed Import diagnostics.
- Emits explicit blocked reasons for not-ready artifacts, missing artifact URI,
  missing destination locator, invalid URIs, missing provider identity evidence,
  and unavailable storage planning.

## Non-Mutation Evidence

Focused tests assert promotion preview does not create Media Sources and does
not create, overwrite, copy, link, or delete files in the media-library root.

## Evidence

- `cargo nextest run -p nako-server managed_import --no-fail-fast`

## Follow-Up

MIS-050 should decide whether promotion apply stays in this lane or splits to a
dedicated follow-on. Apply must require rollback, cleanup, audit, and operator
confirmation gates before any storage mutation is allowed.
