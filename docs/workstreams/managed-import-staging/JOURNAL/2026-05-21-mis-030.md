# 2026-05-21 — MIS-030 App Service Diagnostics

## Scope

Added an app-internal `ManagedImportAppService` for creating and listing
redacted Managed Import Artifact diagnostics.

## Behavior

- Validates target library existence.
- Optionally enriches size/fingerprint from a referenced VFS staging manifest.
- Redacts source URI and hides artifact URI, file name, intended locator,
  fingerprint, and raw diagnostics JSON from diagnostics output.
- Rejects mutating lifecycle states at creation.
- Does not fetch external bytes and does not create Media Sources.

## Evidence

- `cargo nextest run -p taru-server managed_import --no-fail-fast`
