# MBG-030 Session Journal

Date: 2026-05-25

## Summary

Implemented the `/catalog` Admin Web V2 route as a governance-oriented browse
and search surface.

## Changes

- Added `getPublicCatalogItemsBridge` and `getPublicCatalogSearchBridge` in the
  Admin Web API client.
- Added route-local safe projection for public `/items` and `/search` DTOs.
- Added `CatalogBrowsePage` with URL-owned `q`, `facet`, `limit`, and `offset`
  params.
- Updated primary navigation from `/catalog/governance` to `/catalog`, while
  keeping the existing governance queue route linked from the browse page.
- Added a reserved `/items/:itemId` placeholder so browse rows have stable
  detail navigation before MBG-040.
- Added route, bridge, data-source, fallback, and redaction tests.
