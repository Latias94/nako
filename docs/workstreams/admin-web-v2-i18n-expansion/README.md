# Admin Web V2 I18n Expansion

This workstream expands Admin Web V2 localization beyond the app shell and
Media Library management routes. It migrates route-visible UI copy into the
existing English and Simplified Chinese message catalogs while preserving API
enum values, query values, ids, timestamps, diagnostics, and redaction
boundaries.
