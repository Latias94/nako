# AMG-060

## Summary

Closed the Addon Manager Lifecycle Automation lane.

## Closeout

- The first manager-owned registry/plan slot is complete.
- `GET /admin/v1/addons/{addon_id}/manager-plan` exposes the redaction-safe
  snapshot.
- `POST /admin/v1/addons/{addon_id}/manager-plan` records explicit
  operator-confirmed install/update/remove lifecycle intent.
- Marketplace hosting, package signing, provider breadth, rollback/update
  execution, and direct process/container supervision are follow-on lanes.

## Validation

- `cargo fmt --all -- --check`
- `cargo nextest run -p nako-server addon --no-fail-fast`
- `cargo check -p nako-api --tests`
- `pwsh -NoProfile -ExecutionPolicy Bypass -File scripts/official-addon-e2e-smoke.ps1 -NakoImage nako:amg030`

## Notes

- The official addon smoke used the current-source `nako:amg030` image because
  the already published `v0.1.0-alpha.1` image does not contain the new
  manager-plan `POST` route.
