# UPS-010 Journal

Date: 2026-05-19

## Claim

UPS-010 freezes the first public **User Playback State** contract and
**Single-Admin Mode** principal semantics before schema, server routes, SDKs, or
Android UI work begins.

## Decisions

- Added ADR-0028 to define explicit principal resolution.
- **Single-Admin Mode** resolves accepted admin bearer tokens to the stable
  internal `local-admin` principal.
- Public first-slice routes use `/users/me/playback-state/...` and do not expose
  arbitrary user ids.
- The first route set covers state lookup, Continue Watching, progress reports,
  and explicit watched/unwatched transitions.
- Favorites, hidden state, and user rating are deferred from first-slice routes
  but remain **User Playback State** concepts.
- Android device-local resume remains fallback/local cache only.

## Next Task

UPS-020 should implement the repository, SQLite storage, principal-aware
service boundary, and watched threshold behavior against `CONTRACT.md` and
ADR-0028.
