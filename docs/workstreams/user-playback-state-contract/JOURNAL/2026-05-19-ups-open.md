# User Playback State Contract Open Journal

Date: 2026-05-19

## Why This Was Opened

APIC-060 in `android-public-client-api-coverage` required a decision about
server/client **User Playback State**. The correct decision is to split a new
durable workstream because this crosses server storage, public API, SDKs,
Android, smoke fixtures, and user principal semantics.

## Current Boundary

Android device-local resume remains valid local behavior. It is not
server-authoritative and must not drive cross-device Continue Watching claims.

## First Task

UPS-010 should freeze the route contract and principal strategy before any
schema or Android UI changes.
