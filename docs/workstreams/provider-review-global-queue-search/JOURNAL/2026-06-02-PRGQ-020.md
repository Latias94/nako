## Summary

Added the read-only Admin API global Metadata Candidate Review queue route:
`GET /admin/v1/metadata/candidate-reviews`.

## Implementation Notes

- Added `MetadataCandidateReviewQueueFilter` and a global
  `list_metadata_candidate_reviews` repository method.
- Implemented SQLite and PostgreSQL queue queries with repository-owned
  `status` and `provider` filters, stable ordering, and page limit/offset.
- Added `AdminMetadataCandidateReviewQueueResponse` and synchronized Admin
  TypeScript contract output for both frontends.
- Added the Axum route and query parsing for `status`, `provider`, `limit`,
  and `offset`.
- Kept the route read-only: queue reads build application plans for display
  but do not apply mappings, canonical metadata, status changes, or hierarchy
  updates.
