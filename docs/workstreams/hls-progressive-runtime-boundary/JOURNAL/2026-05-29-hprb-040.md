# HPRB-040 Journal — Typed HLS Artifact Reconstruction

Date: 2026-05-29
Status: DONE

## Summary

Moved HLS artifact manifest reconstruction into `nako-transcode` so server
playback no longer parses `request_key` substrings to infer HLS output shape or
request-variant data.

## Changes

- Added `HlsArtifactSpec` in `nako-transcode::artifact`.
- Reconstructed single-variant and adaptive HLS manifests from persisted
  transcode request identity.
- Preserved adaptive ladder, audio rendition, subtitle rendition, and segment
  container reconstruction without a schema migration.
- Updated server `hls_artifact.rs` to validate session readiness and delegate
  manifest reconstruction to `HlsArtifactSpec`.
- Confirmed no server-local HLS request-key parser helpers remain in playback
  artifact reconstruction.

## Validation

- `cargo nextest run -p nako-transcode hls_request_variant --no-fail-fast`
- `cargo nextest run -p nako-server hls_artifact --no-fail-fast`
