# HPRB-020 — HLS Output Publication Policy

Date: 2026-05-29
Status: DONE

## Changes

- Added `HlsOutputPublicationPolicy` to `nako-transcode`.
- Kept `AtomicOnCompletion` as the default `FfmpegHlsRunner` behavior.
- Added `ServeWhileRunning`, which writes HLS output to the final session
  directory while FFmpeg is still running.
- Renamed cancelled HLS runner cleanup output to `discarded_output_dir` because
  it can now be either a temporary directory or a serve-visible output directory.
- Added tests for atomic promotion, running-output visibility, and cleanup after
  serve-visible failure.

## Validation

```text
cargo nextest run -p nako-transcode hls_runner --no-fail-fast
cargo nextest run -p nako-transcode hls --no-fail-fast
```

Both commands passed on 2026-05-29.
