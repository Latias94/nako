# HPRB-050 Journal — Manifest-Aware Playlist Auth Decoration

Date: 2026-05-29
Status: DONE

## Summary

Consolidated HLS entry playlist authoring, playback/transcode session route
binding, and browser/renderer auth query decoration behind one manifest-aware
server playback boundary.

## Changes

- Added `author_hls_session_playlist` in `app/playback/playlist.rs`.
- Bound playlist media URIs through `HlsArtifactManifest::artifact_for_name`
  before exposing `/playback/sessions/{id}/hls/segments/{artifact}` routes.
- Added `HlsPlaylistUrlDecoration` so browser tickets and renderer tickets are
  appended while route binding happens, including quoted `URI="..."` HLS
  attributes.
- Passed browser and renderer transport query strings through playback app
  requests instead of re-scanning playlists in `http/playback.rs`.
- Removed HTTP-local HLS playlist ticket append helpers and moved their
  behavior into playlist authoring tests.
