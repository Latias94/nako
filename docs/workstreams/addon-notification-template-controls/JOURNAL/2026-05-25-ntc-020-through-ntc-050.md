# 2026-05-25 — NTC-020 Through NTC-050

Status: DONE

Implemented safe summary template controls in `nako-notification-bridge`.

Key decisions:

- `NAKO_NOTIFICATION_BRIDGE_TEMPLATE_SUMMARY` is sidecar-owned.
- Allowed tokens are `event_id`, `event_kind`, `subject_kind`, `subject_id`,
  `occurred_at`, `attempt`, and `payload_keys`.
- Raw event payload values are not available to templates.
- Unknown or malformed tokens fail closed before provider sends.
- Health and diagnostics expose only configured/valid/status facts and never
  echo template text.
