# Admin Web V2 Settings Mutation Authority

This workstream defines and implements the first safe settings mutation path
for Admin Web V2 after the read-only `/settings` route. It starts with route/API
readiness and source-of-truth decisions because the current system config
surface is diagnostic-only.
