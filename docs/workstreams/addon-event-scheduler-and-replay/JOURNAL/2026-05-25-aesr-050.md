# AESR-050 — Forced Replay And Filters

Status: DONE
Date: 2026-05-25

## What Changed

- Added explicit Addon Event forced replay through
  `POST /admin/v1/events/{event_id}/addon-events/replay`.
- Added durable replay audit fields to delivery attempts:
  `forced_replay` and `replay_reason_code`.
- Kept normal delivery idempotent after success while allowing forced replay to
  create a new attempt for the same addon/event/subscription tuple.
- Added host-side subscription filter evaluation for simple event facts before
  durable claims and sidecar calls.
- Added redaction-focused HTTP tests for replay, filter match, and filter skip
  behavior.
