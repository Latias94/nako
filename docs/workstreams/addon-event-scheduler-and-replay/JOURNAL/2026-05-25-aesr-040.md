# AESR-040 — Scheduler Runtime Integration

Status: DONE
Date: 2026-05-25

## What Changed

- Added disabled-by-default `addon_event_scheduler` server config with interval,
  error backoff, batch size, and event concurrency.
- Wired `AddonAppService` to start a supervised `addon_event_scheduler` runtime
  task when the config is enabled.
- Added a scheduler tick that scans pending outbox events in bounded batches,
  checks redaction-safe due/retry-due scheduler work, and dispatches through the
  existing durable delivery path.
- Added startup and admin overview diagnostics for whether the scheduler task
  started.
- Added focused tests for runtime supervision/shutdown, automatic due event
  delivery, configured event concurrency, config parsing, and existing config
  literals.
