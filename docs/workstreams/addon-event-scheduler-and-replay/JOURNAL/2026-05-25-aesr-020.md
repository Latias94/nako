# AESR-020 — Due Work Selection

Status: DONE
Date: 2026-05-25

## What Changed

- Added `AddonEventSchedulerWorkRecord` as a payload-free repository fact type.
- Added `list_addon_event_scheduler_work(event_id)` to the addon event delivery
  repository, with SQLite and PostgreSQL implementations.
- Added a DB contract covering enabled-addon filtering, executable/deferred
  event routing plans, attempt summaries, retry timestamps, and SQLite/PostgreSQL
  parity.
- Added `GET /admin/v1/events/{event_id}/addon-event-scheduler/work` for
  redaction-safe admin diagnostics.
- Server diagnostics now compute due, retry-due, waiting-retry,
  already-succeeded, exhausted, in-flight, and deferred statuses using routing
  plans, current grants, manifest max attempts, and attempt summaries.
