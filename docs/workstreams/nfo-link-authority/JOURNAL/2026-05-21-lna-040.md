# 2026-05-21 — LNA-040 NFO Authority Preview

## Goal

Expose a non-mutating NFO authority preview before any sidecar write/import
mutation.

## Changes

- Added `NfoAuthorityPreview*` request, summary, decision, action, and reason
  model in `taru-nfo`.
- Added `NfoService::preview_authority`.
- Added `NfoAppService::preview_library_nfo_authority`.
- Preview covers:
  - export create;
  - export skip existing sidecar when `force=false`;
  - forced-preserving export update;
  - backup requirement for forced existing-sidecar update;
  - import sidecar-read/update intent;
  - import missing-sidecar skip;
  - policy rejection;
  - parse/render/preservation/storage failure classification.
- Preview deliberately does not call repository commit or storage write APIs.

## Validation

```powershell
cargo nextest run -p taru-nfo authority_preview --no-fail-fast
cargo nextest run -p taru-server nfo_authority_preview --no-fail-fast
cargo nextest run -p taru-nfo --no-fail-fast
cargo nextest run -p taru-server nfo --no-fail-fast
cargo fmt --all -- --check
git diff --check
```

All final runs passed. The first red/green app run failed because preview types
were not re-exported from `taru-nfo`; re-exporting them fixed the public crate
boundary.
