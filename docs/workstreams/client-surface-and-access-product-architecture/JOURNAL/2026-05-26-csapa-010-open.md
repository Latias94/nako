# CSAPA-010 Open

Date: 2026-05-26

Opened `client-surface-and-access-product-architecture` as a docs-first
planning lane.

Key decisions recorded:

- Admin Web remains the operator console.
- Media Web should become the browser local-media browse/play surface and must
  consume Public Client API rather than Admin API.
- Public registration should not be enabled by default. Start with
  Single-Admin Mode, then admin-created local accounts, then Library Access and
  optional invitations.
- Coarse roles should come before fine-grained permissions:
  `administrator`, `library_manager`, and `viewer`.
- Permission-gated Management Context Links should let admins move from media
  discovery/playback problems into scan, metadata, artwork, NFO, playback
  support, settings, jobs, and session workflows.
- Desktop playback should be Media Web-centered, with Tauri as a shell and a
  native playback core for serious local media playback.

No code changed in this task.
