# ACAD-060 Journal — Home Section Read Model And Progressive Artwork

Date: 2026-05-22
Owner: codex
Status: DONE

## Scope

Implemented the Home read-model slice from the Android client architecture
workstream. The goal was to replace the previous coarse Home content state with
section-level availability while preserving existing Public Client API semantics
and token-safe diagnostics.

## Changes

- Added `HomeReadModel` behind `BrowseUiState.Content`.
- Added `HomeSectionState` for independently available, unavailable, and not
  requested Home sections.
- Added `HomeArtworkState` and `HomeArtworkFailure` so Managed Artwork
  enrichment can fail without hiding visible Media Items.
- Updated `ClientBrowseDataSource.loadHome()` so Media Libraries and Visible
  Titles are primary sections. Home returns partial content when either primary
  section succeeds, and full failure only when both primary sections fail or the
  access token is missing.
- Converted Continue Watching failures into degraded Home section state.
- Updated `HomeScreen` and `LibrariesScreen` to render section-level
  unavailable states with retry affordances instead of silently showing failed
  sections as empty lists.
- Preserved compatibility accessors on `BrowseUiState.Content` while making
  `state.home` the preferred interface for new code.

## Tests Added Or Strengthened

- `home keeps items visible when library section fails`
- `home records continue watching failure as degraded section`
- `home records artwork failures without blocking visible items`

Existing first-paint behavior remains covered by `BrowseSessionLoadingTest`,
where Home load enters `BrowseUiState.Loading` before content publication.
