Task: ACAD-020 — Client Runtime And Request Execution Seam
Status: DONE

## Summary

Introduced `PublicClientRuntime` as the deep Android-owned Public Client API
runtime seam above `PublicClientApiExecutor`.

The runtime now owns:

- missing access-key validation before request builders run;
- authenticated JSON execution;
- JSON decode failure mapping to `PublicApiFailureKind.InvalidResponse`;
- authenticated raw response execution for session preflight;
- Rust-core safe-preview preservation for connection probe steps;
- transport failure propagation through existing executor redaction policy.

Route-family clients still own:

- Browse, Playback, User Playback State, and Connection failure categories;
- user-facing message mapping;
- generated SDK DTO to Android product-model mapping;
- Media3/player and profile/token storage boundaries.
