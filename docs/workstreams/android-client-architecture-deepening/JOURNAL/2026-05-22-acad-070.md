## Scope

Performed the Android persistence, lifecycle, Gradle/UniFFI validation, and stale
transition-code sweep. The task allowed small safe cleanup and required larger
scope to be split or deferred explicitly.

## Implemented Cleanup

- Added `androidx.lifecycle:lifecycle-runtime-compose`.
- Replaced Compose `collectAsState()` with `collectAsStateWithLifecycle()` in:
  - `NakoAndroidApp.kt`
  - `NakoBrowseShell.kt`
  - `NakoConnectionShell.kt`
  - `PlaybackPlayerRoute.kt`

This keeps hot UI `StateFlow` collection tied to the visible lifecycle instead
of collecting while a composable is stopped.

## Decisions

- Keep SharedPreferences-backed server profile, playback preference, and device
  playback-position stores for now. They are small, behind interfaces, and
  covered by tests.
- Keep `AndroidSecureTokenVault` behind `TokenVault`. Replacing deprecated
  AndroidX Security APIs should be a focused token-vault migration.
- Defer DataStore/Room until settings/profile editing, downloads/offline, local
  catalog cache, or richer migration requirements make the storage model deeper.
- Defer Gradle module split until dependency or build-time pressure appears.
- Defer CI/device-farm and multi-ABI policy hardening to a release/CI lane.
