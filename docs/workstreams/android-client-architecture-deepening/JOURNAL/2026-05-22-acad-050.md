# ACAD-050 Journal — UI Design-System And Screen Modularization

Date: 2026-05-22
Task: ACAD-050
Status: DONE

## Intent

Separate generic design-system ownership from Taru media-specific presentation
and move testable display-model/copy builders out of oversized Composable route
files without changing route behavior, accessibility labels, or diagnostics.

## Changes

- Removed generic design-system pass-through wrappers from
  `BrowseComponents.kt`.
- Updated browse and screen callers to import these primitives directly from
  `dev.taru.android.ui.components`:
  - `TaruScreenColumn`
  - `TaruSectionHeader`
  - `TaruSurfaceCard`
  - `TaruStatusChip`
  - `TaruStatusPill`
  - `TaruIconBadge`
  - `TaruArtworkBackdrop`
  - `TaruPressableScale`
- Added `SourcePickerPresentation.kt` for Source Picker display models,
  source selection, playback-mode copy, resume copy, and probe fact labels.
- Added `DetailPresentation.kt` for Detail metadata targets, credit
  relationships, hero facts, collection copy, and hierarchy copy.
- Kept `BrowseComponents.kt` as a Taru media/browse presentation module rather
  than a generic component registry.
