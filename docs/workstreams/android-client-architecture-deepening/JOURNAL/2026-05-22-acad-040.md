## Summary

Introduced an Android-owned playback runtime seam around the existing player
route host.

The final ownership is:

- `PlaybackSessionRuntime` owns route-scoped attach/prepare/retry/back/dispose,
  player state, `Player` access for `PlayerView`, and exit-effect dispatch.
- `PlaybackSessionRuntimeFactory` owns creation of route-scoped playback
  runtimes.
- `AndroidPlaybackSessionRuntimeFactory` owns app-context, token-vault,
  Media3-engine, playback-client, position-store, and exit-effect-scope
  composition.
- `PlayerRouteHost` implements the runtime interface and keeps tested event
  mapping and idempotent exit behavior.
- `PlaybackPlayerRoute` now stays closer to rendering, `PlayerView` binding,
  UI back/retry dispatch, and diagnostics clipboard behavior.

MediaSession, PiP, Cast, and track-selection remain follow-ons behind the new
runtime seam.
