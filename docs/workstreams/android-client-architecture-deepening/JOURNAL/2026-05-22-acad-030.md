## Summary

Introduced an explicit browse effect seam for saveable-state publication and
route-displayed load intents.

The final ownership is:

- `BrowseSessionEffectCoordinator` owns route-display deduplication,
  saveable-state publication timing, and `BrowseSessionLoadIntent` emission.
- `BrowseShellHost` owns host lifetime and wires the coordinator to
  `BrowseSession`.
- `BrowseSession` remains the deterministic state machine and async action
  entry point.
- `BrowseRouteLoadingSession` owns route-family loading and treats
  `TaruRoute.Player` as a transient route that does not clear previous detail
  state.
- `BrowseRouteStatePolicy` continues to own stale-response invalidation.
