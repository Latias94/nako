# AOTDC-020 Credential Model

Date: 2026-05-24

Implemented the first outbound task-dispatch credential slice.

What changed:

- `addon_registrations` now store `outbound_task_dispatch_secret_env`.
- `RegisterAddonRequest` accepts the same env reference.
- `AdminAddonRegistrationSummary` echoes the env reference for operator
  visibility.
- `crates/nako-server/src/app/addons.rs` now normalizes env names and exposes a
  host-side resolver that returns redaction-safe errors for missing or empty
  env values.

Validation:

- `cargo check -p nako-api -p nako-db -p nako-server`
- `cargo nextest run -p nako-addon-client --no-fail-fast`
- `cargo nextest run -p nako-db addon --no-fail-fast`
- `cargo nextest run -p nako-server register_addon_routes_disabled_by_default_and_validate_contract resolves_outbound_task_dispatch_secret_from_env_reference missing_outbound_task_dispatch_secret_reports_safe_error rejects_invalid_outbound_task_dispatch_secret_env_names --no-fail-fast`
- `cargo run -p nako-api --example emit-admin-typescript-contract -- --output apps/admin-web/src/adminApi/generated/contract.ts`
