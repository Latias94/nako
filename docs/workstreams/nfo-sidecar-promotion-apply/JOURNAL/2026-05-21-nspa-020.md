# NSPA-020 — Durable Sidecar Apply Acceptance And Audit

Date: 2026-05-21
Status: Done

## Summary

Added the durable persistence boundary for accepted NFO sidecar apply attempts.
The new domain is intentionally separate from Managed Import promotion: it
tracks accepted NFO authority preview facts, idempotency, policy version,
operation kind, state, and redacted audit outcome fields without mutating
sidecar files or canonical metadata.

## Changes

- Added `NfoSidecarApplyId`, operation/state enums, request records, and stored
  audit records in `taru-core`.
- Added `NfoSidecarApplyRepository` with upsert/get/idempotency/list/state
  transition methods.
- Added SQLite and PostgreSQL migrations for `nfo_sidecar_applies`.
- Added SQLite/PostgreSQL repository adapters and facade dispatch.
- Added a backend-neutral DB contract test for persistence, idempotency-key
  lookup, item listing, state transitions, and safe audit messages.
