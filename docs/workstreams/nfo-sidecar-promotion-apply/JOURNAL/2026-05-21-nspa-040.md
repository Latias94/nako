# NSPA-040 Journal — Export Sidecar Apply

Date: 2026-05-21
Owner: codex
Status: DONE

## Scope

Implemented accepted NFO export sidecar apply. The server revalidates the
accepted preview before mutation, delegates rendering/preservation to
`nako-nfo`, writes only through VFS storage APIs, and records durable audit
state transitions.

## Red Gate

```powershell
cargo nextest run -p nako-server nfo_sidecar_apply_exports_accepted_create_preview_and_commits_audit --no-fail-fast
```

Expected failure before implementation: the new test could not compile because
`ApplyNfoSidecarApplyRequest` and `apply_sidecar_apply` did not exist.

## Implementation

- Added `ApplyNfoSidecarApplyRequest`.
- Added `NfoAppService::apply_sidecar_apply`.
- Replays already committed apply records idempotently.
- Revalidates current NFO authority preview before sidecar mutation.
- Rejects stale accepted export apply as `FailedBeforeMutation`.
- Applies export through `NfoService::export_media_source`.
- Records `WritingSidecar`, `Committed`, and failed-before-mutation audit
  outcomes with redacted JSON.
