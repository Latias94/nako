# NSPA-050 Journal — Import Authority Apply

Date: 2026-05-21
Owner: codex
Status: DONE

## Scope

Implemented accepted NFO import sidecar apply. The server now revalidates the
accepted NFO authority preview before metadata mutation, delegates sidecar read
and metadata merge to `nako-nfo`, applies local authority through repository
commit boundaries, and records durable redacted audit state transitions.

## Red Gate

```powershell
cargo nextest run -p nako-server nfo_sidecar_apply_imports_accepted_sidecar_into_metadata_and_locks --no-fail-fast
```

Expected failure before implementation: accepted import apply returned
`Unsupported("NFO sidecar apply currently supports export sidecar records only")`.

## Implementation

- Added `NfoImportSourceRequest` and `NfoImportSourceSummary`.
- Added `NfoService::import_media_source` for single-source import apply.
- Split server apply dispatch into export/import branches.
- Added import audit outcomes for `ImportingMetadata`, `Committed`, and
  failed-before-mutation states.
- Added content fingerprints to NFO authority preview decisions so accepted
  import apply rejects changed sidecar content even when the preview action is
  still `Update`.
- Kept import-only apply from writing the sidecar file.
