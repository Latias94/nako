# Android Client Foundation Closeout

Status: COMPLETE
Date: 2026-05-18

## Closeout Decision

The Android client foundation lane is complete. The target foundation now
exists:

- Android app scaffold under `apps/android`;
- Public Client API connection/auth with secure token references;
- minimal Home/Libraries/Search/Settings and Media Item detail loop;
- playback decision and public playback request construction;
- Media3 playback smoke through a real Taru public playback route;
- public playback session inspection/cancellation client support;
- device-local transient playback position scoped by server profile, Media
  Item, and Media Source.

The remaining work is not foundation cleanup. It is new product/API scope and
should be split into follow-on lanes.

## Follow-On Boundaries

- Authoritative **User Playback State** and cross-device Continue Watching
  require a Public Client API contract before Android UI claims them.
- Reliable native-client cancellation on exit needs a public playback session
  handle in stream responses or a structured playback launch envelope.
- Durable device-local transient position needs an Android local state store
  decision.
- Downloads/offline, Cast, PiP, track/subtitle depth, external-player handoff,
  Android TV, iOS, and shared Rust/UniFFI packaging remain separate lanes.
