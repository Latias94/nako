Status: COMPLETE
Date: 2026-05-18

## Scope

Completed the playback decision slice without activating Media3 playback. The
goal is to connect Media Item Detail source selection to explicit Public Client
API playback routes and produce client-safe prepared playback targets for
`ACF-050`.

  diagnostics, playback capability query modeling, and `NakoPlaybackClient`.
- Implemented `GET /sources/{source_id}/playback/decision`.
- Implemented request target builders for:

  - remux stream;
  - HLS playlist;
  - HLS session segment.
- Added recommended target selection from playback decision mode.
- Wired Media Item Detail to list candidate Media Sources, request playback
  decisions, and show a safe prepared route preview.
