# ACF-050 Media3 Playback Smoke

Status: COMPLETE
Date: 2026-05-18

## Scope

Added the first real Android playback path without claiming resume/progress,
downloads, cast, PiP, or external-player behavior.

## Changed

- Added AndroidX Media3 ExoPlayer, HLS, and UI dependencies.
- Added a `PlaybackLaunchRequest` model that keeps the real HTTP request for
  Media3 while exposing only a safe redacted request preview through debug
  output.
- Added a full-screen PlayerView-backed Compose player route.
- Wired Media Item Detail `Start playback` to launch from the prepared ACF-040
  playback target after a successful playback decision.
- Released ExoPlayer when leaving the player route.
- Improved small source-size labels from rounded `0 MiB` to KiB/B output.
