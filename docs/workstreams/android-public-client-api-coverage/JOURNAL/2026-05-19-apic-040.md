# APIC-040 Session Journal

Date: 2026-05-19

## Goal

Decide whether Library Detail and library source inventory should become
first-class Android routes, then implement or explicitly defer.

## Decision

Implemented. The Public Client API provides a library summary route and a
paginated source inventory route, so Android can expose a real structural
Library Detail page.

The page deliberately stays source-inventory oriented. It does not present a
full library poster grid because `/libraries/{library_id}/sources` returns
Media Sources, not a library-scoped Media Item browse response.

## Work Completed

- Added `LibraryResponse`, `LibrarySourcesResponse`, and
  `LibrarySourceResponse` Android DTOs.
- Added `NakoBrowseClient.libraryDetail` and
  `NakoBrowseClient.librarySources`.
- Added `LibraryDetailRouteContent` with library summary and safe source
  inventory rows.
- Added `NakoRoute.LibraryDetail`, route stack handling, and navigation state
  save/restore support.
- Moved `MediaProbeDto`, `MediaStreamDto`, and `ClientMediaStreamKind` into the
  shared Android media package so browse and playback can both consume public
  probe data cleanly.
- Redacted local roots and source locators from DTO `toString` output.
