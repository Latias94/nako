# AAO-050 Journal — Hosted Surface Read Models

Date: 2026-05-21

## Intent

Add Admin read models for Addon manifest surfaces so the Admin Web Console can
render Addon Entry Points, Hosted Pages, configuration metadata, Secret
Reference declarations, Addon Tasks, and Addon Event Subscriptions without
turning hosted pages into trusted embedded Admin UI.

## Implementation

- Added `AdminAddonSurfacesResponse` and nested surface DTOs to
  `taru-api::extension`.
- Added `GET /admin/v1/addons/{addon_id}/surfaces`.
- Reused the stored manifest snapshot and revalidated it before producing the
  read model.
- Derived Hosted Page URLs from the stored manifest `base_url` and declared
  absolute Hosted Page path.
- Kept Secret Reference fields as declarations only; no resolved secret values
  are exposed.
- Added HTTP coverage for Entry Points, Hosted Pages, Configuration Schema,
  Secret Reference fields, Addon Tasks, and Addon Event Subscriptions.
- Asserted the response does not contain admin bearer tokens, Addon Tokens,
  launch secrets, or resolved secret values.
