# AAO-010 Journal — Contract And Goal Baseline

Date: 2026-05-21

## Intent

Freeze Admin Addon Operations MVP route and lifecycle semantics before writing
implementation code.

## Decisions

- Addon unregister is a terminal lifecycle state, not physical deletion.
- `unregistered` preserves registration, token, Side Effect, and Addon Artwork
  Candidate audit history.
- Unregister revokes active Addon Tokens, clears accepted grants, and makes
  runtime Addon Token authentication fail.
- AAO does not mount `DELETE /admin/v1/addons/{addon_id}`.
- Reserved MVP routes:
  - `PATCH /admin/v1/addons/{addon_id}/status`;
  - `POST /admin/v1/addons/{addon_id}/unregister`;
  - `POST /admin/v1/addons/{addon_id}/health-check`;
  - `GET /admin/v1/addons/{addon_id}/surfaces`;
  - `POST /admin/v1/addons/{addon_id}/diagnostics/resource-call`.
- Addon Manager process/package lifecycle remains out of scope.
