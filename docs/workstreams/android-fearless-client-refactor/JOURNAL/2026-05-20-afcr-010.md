# AFCR-010 Public Client API Adapter

Date: 2026-05-20
Owner: codex
Status: DONE

## Summary

Introduced a route-independent `PublicClientApiExecutor` for Android Public
Client API calls and migrated the connection, browse, playback, and User
Playback State clients to it.

## Code Changes

- Added `PublicClientApiExecutor` with shared handling for:
  - bearer and unauthenticated requests;
  - safe request previews and bearer redaction;
  - transport failures, TLS failures, HTTP failures, public error envelopes;
  - API-version response headers;
  - JSON decode failures;
  - common path/query URL helpers.
- Simplified route clients so they own route construction and route-specific
  failure category mapping instead of duplicated protocol policy.
- Added playback tests for session-preflight HTTP failure and API-version
  failure through the shared executor.
