# AFCR-040 Journal — Transport And Network Security

Date: 2026-05-21

## Summary

Completed the Android transport and network-security hardening slice for the
client foundation. Production behavior now rejects cleartext HTTP explicitly,
while debug/local-development behavior remains possible through an explicit
policy and manifest overlay.

## Changes

- Added `ConnectionSecurityPolicy` with production default deny and explicit
  local-development allow policy.
- Added `CleartextHttpNotPermittedException` as a final transport guard.
- Updated `JdkNakoHttpTransport` to:
  - enforce the configured security policy before opening a connection;
  - always disconnect in `finally`;
  - preserve the existing `NakoHttpTransport` seam.
- Updated `NakoConnectionClient` to reject insecure HTTP before transport or
  token use under production policy, returning token-safe diagnostics.
- Added `ConnectionFailureCategory.InsecureCleartextHttp`.
- Removed global cleartext allowance from the main manifest.
- Added debug manifest cleartext allowance for explicit local development.
- Wired `AndroidNakoAppEnvironmentFactory` through the production security
  policy by default.
