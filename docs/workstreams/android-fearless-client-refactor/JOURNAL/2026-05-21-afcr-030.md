# AFCR-030 Journal — Browse State Deepening

Date: 2026-05-21

## Summary

Completed the P1 browse state boundary. `BrowseSession` no longer directly owns
every route family, stale-response counter, source/probe/playback selection
transition, and playback-start transition. It now composes focused deep modules
with behavior-preserving tests.

## Changes

- Added `BrowseSessionStore` as the state mutation seam for browse modules.
- Added `BrowseSessionNavigation` for pure navigation reduction plus route
  preparation handoff.
- Added `BrowseRouteStatePolicy` to own route-family preparation and request
  id invalidation.
- Added `BrowseRouteLoadingSession` for route-aware loading of library detail,
  person detail, relationship indexes, facets, and item detail delegation.
- Added `BrowseItemDetailSession` for item detail loading, source selection,
  source probes, playback selection loading, resume resolution, and stale
  response checks.
- Added `BrowseSearchSession` for search submit/retry and stale search result
  protection.
- Added `BrowsePlaybackSession` for start-playback orchestration and Player
  route opening.
- Added `BrowseSessionRouteStateTest` and shared browse test fixtures so route
  preparation, unsupported facet API gaps, stale request invalidation, and
  transient Player routes are tested at the new module seam.
