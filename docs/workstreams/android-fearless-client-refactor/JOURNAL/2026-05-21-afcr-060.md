# AFCR-060 Journal — Product UI Copy, Accessibility, Localization Seams

Date: 2026-05-21

## Summary

Completed AFCR-060 for the first key Android surfaces.

Implemented:

- Added `apps/android/app/src/main/java/dev/nako/android/ui/NakoStrings.kt` and
  Android string resources for stable actions and labels: Back, Retry, Change
  server, Search, Load more, Copy diagnostics, server access key, and player
  session accessibility.
- Rewrote visible copy away from protocol/internal terms such as API gaps,
  route, access token, Media Source, User Playback State, current response, and
  source facts. The visible product language now uses server compatibility,
  sign-in key, titles, versions, watch progress, and server-backed lists.
- Added semantics/roles/labels for key custom controls: settings rows, active
  server profile panel, sign-out panel, status chips/pills, pressable media and
  library cards, relationship rows, source picker radio rows, library source
  rows, and player session status.
- Preserved sanitized advanced diagnostics and token-safe reporting.
- Productized shared client diagnostics copy in connection, browse, playback,
  and watch-progress clients so failures surface media-client language.

## Notes

`DESIGN.md`. I used the Android material expressive UI design workstream and
AFCR docs as the product UI context, then applied the product-register guidance:

migration. Stable high-reuse labels are now resource-backed; dynamic diagnostic
reports remain generated from sanitized runtime facts.
