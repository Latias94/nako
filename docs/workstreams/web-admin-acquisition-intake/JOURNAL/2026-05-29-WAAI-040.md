## Decision

Watch-folder discovery mutation controls are split to a future guarded mutation
lane. WAAI remains the read-only Acquisition Intake route lane.

## Evidence

The generated Admin API exposes:

```text
POST /admin/v1/acquisition/intake/watch-folder-discovery
```

The response advertises `writes_library`, `managed_import_artifacts_created`,
and `promotion_apply`, which is useful for safety UX. Even when direct library
writes and promotion apply are false, discovery may record intake candidates
and create Managed Import artifacts, so the UI needs mutation-specific guards.

## Follow-On Requirements

The future mutation lane must define permission, confirmation, idempotency,
redacted results, loading and failure states, route/local state behavior,
request serialization tests, response mapping tests, and rendering assertions
that no raw paths, credentials, prompt bodies, source locators, or downloader
internals appear.
