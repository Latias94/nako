# 2026-05-25 — ANP-020 Provider Configuration Contract

Task: ANP-020
Status: DONE

## Implementation

Added the `http_webhook` sidecar configuration contract in
`nako-notification-bridge`:

- `NAKO_NOTIFICATION_BRIDGE_HTTP_WEBHOOK_ENABLED`;
- `NAKO_NOTIFICATION_BRIDGE_HTTP_WEBHOOK_URL`;
- `NAKO_NOTIFICATION_BRIDGE_HTTP_WEBHOOK_SHARED_SECRET`;
- `NAKO_NOTIFICATION_BRIDGE_HTTP_WEBHOOK_SECRET_HEADER_NAME`;
- `NAKO_NOTIFICATION_BRIDGE_HTTP_WEBHOOK_TIMEOUT_MS`.

The provider remains send-disabled. Health and diagnostics expose only safe
configuration facts: enabled, target configured/valid, secret configured,
custom header name configured, status, timeout, and send path disabled.

Operator docs now state that webhook URL and secret are injected into the
sidecar by deployment tooling, not stored in Nako core.
