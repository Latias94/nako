# 2026-05-25 — AEF-030 Official Catalog Drift Prevention

Status: DONE

Added `nako-official-addon-catalog` as the shared official addon facts crate.
Nako server now resolves the built-in official metadata scraper catalog entry
from that crate, and the official metadata scraper runtime manifest in
`nako-official-addons` uses the same facts when building `/manifest.json`.

Key decisions:

- The source catalog remains discovery and install-guide data only. It does
  not install packages, start containers, create registrations, or enqueue
  jobs.
- The catalog descriptor uses the official container shape so Docker Compose
  guidance can point at a real official image instead of a placeholder binary
  shape.
- The official sidecar still owns runtime configuration and provider enablement
  through its own `Config`; the shared crate only supplies stable manifest and
  descriptor structure.

Validation:

```powershell
cargo nextest run -p nako-server addon_source_catalog --no-fail-fast
cargo nextest run -p nako-official-addon-catalog --no-fail-fast
cargo nextest run -p nako-metadata-scraper addon_manifest checked_in_example_manifest_matches_runtime_manifest --no-fail-fast
cargo check -p nako-official-addon-catalog -p nako-server --tests
cargo check -p nako-metadata-scraper --tests
```

All passed. The official addon commands were run in
`F:\SourceCodes\Rust\nako-official-addons`.
