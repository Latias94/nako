# AAD-060 — Library File Write Runtime

Date: 2026-05-21

## Summary

Deepened the shipped Library File Write path from an NFO-only Adapter into a
Taru-owned runtime seam. The public behavior is intentionally unchanged and
still only supports MediaSource-targeted NFO Export.

## Code Notes

- `AddonLibraryFileWriteAdapter` now delegates to
  `AddonLibraryFileWriteRuntime`.
- The runtime owns:
  - typed payload to command normalization;
  - file-role dispatch;
  - MediaSource target resolution;
  - Media Library lookup;
  - file-write permit acquisition;
  - writable-storage validation;
  - first-party NFO/VFS export delegation;
  - redacted outcome/report shaping.
- The apply report now includes safe IDs, target kind, write mode, backup
  policy, and aggregate counters, but still excludes Source Locators, storage
  URIs, local paths, backup URIs, raw NFO XML, file contents, payload JSON, and
  provenance JSON.

## Handoff

Continue with AAD-070 Admin Addon API and DTO shielding. Do not broaden Library
File Write to subtitle, arbitrary sidecar assets, broader NFO, or queued
execution inside this task; those remain separate product slices.
