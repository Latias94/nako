# AAD-040 Journal — Protected Write Payload Contracts

Date: 2026-05-21

## Intent

Move shipped Protected Write payload shapes from private server structs to
explicit Addon-facing contracts.

## Changes

- Added `AddonMetadataPatch`, `AddonArtworkWritePayload`, and
  `AddonLibraryFileWritePayload` to `taru-addon-protocol`.
- Added supporting protocol enums for artwork intent/kind/source and library
  file role/write policy.
- Updated server Adapters to parse the protocol DTOs while keeping Taru-only
  validation, merge, candidate, storage, and report logic in `taru-server`.
- Added protocol wire-shape tests.
- Added small reference Addon helper builders for metadata and NFO payloads.
- Updated HTTP API and Addon Author Guide documentation.
