# AAD-050 — Addon Manifest Depth

Date: 2026-05-21

## Summary

Deepened the Addon Manifest protocol contract without changing the current
Addon Protocol Version. Added compatible manifest declaration fields for:

- Addon Entry Points;
- Addon Hosted Pages;
- Addon Configuration Schema;
- Secret Reference fields;
- Addon Event Subscriptions;
- Addon Tasks.

The new fields are optional and defaulted for deserialization. Empty optional
collections are skipped during serialization so existing minimal manifests keep
their compact wire shape.

## Code Notes

- `nako-addon-protocol` owns the new declaration DTOs and validation.
- Validation now rejects duplicate declaration IDs within each declaration
  class, relative declaration paths, undeclared declaration scopes, entry
  points referencing unknown hosted pages, non-object configuration schemas,
  and invalid task timeout/retry bounds.
- `nako-reference-addon` now publishes a sample entry point, hosted page, and
  configuration schema.
- Server registration tests cover valid manifest declarations and invalid
  declaration scopes through the public registration route.

## Validation

- `cargo check -p nako-addon-protocol -p nako-reference-addon -p nako-server --tests`
- `cargo nextest run -p nako-addon-protocol --no-fail-fast`
