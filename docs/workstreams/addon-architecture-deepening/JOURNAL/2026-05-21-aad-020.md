# AAD-020 Journal — Addon Side Effect Runtime Depth

Date: 2026-05-21

## Intent

Make Addon Side Effect lifecycle a deeper runtime boundary before adding
idempotency fingerprints and more Addon breadth.

## Changes

- Added `crates/taru-server/src/app/addons/runtime.rs` with
  `AddonSideEffectRuntime`.
- Reduced `intake.rs` to an App Service adapter that delegates submission into
  the runtime.
- Extracted shared Addon principal resolution and grant authorization helpers
  from `principal.rs` so `/addon/v1/access-check` and Side Effect submission
  use the same authority behavior.
- Reworked Metadata, Artwork, and Library File Write Adapters to return
  `AddonSideEffectApplyCommand`.
- Centralized validation rejection, apply outcome persistence, metadata write
  commit execution, and apply failure taxonomy in
  `AddonSideEffectApplyRouter`.
