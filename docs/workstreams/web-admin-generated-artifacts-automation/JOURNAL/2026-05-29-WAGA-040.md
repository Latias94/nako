## Decision

Review-plan and accept/reject mutation controls are split to a future guarded
mutation lane. WAGA remains the read-only Generated Artifacts route lane.

## Evidence

The generated Admin API exposes review-plan and review routes, but review
actions change Generated Artifact status and participate in an Acceptance
Workflow. Even when boundary flags prove that direct canonical metadata,
sidecar, or library-file writes are not applied immediately, the UI still needs
mutation-specific route shape, confirmation, idempotent replay handling,
result/error display, cache invalidation, and redaction tests.

## Follow-On Requirements

The future mutation lane must define permission/readiness disabled states,
confirmation, boundary display, idempotent replay handling, result/error
rendering, cache invalidation, request serialization tests, response mapping
tests, and rendering assertions that no raw prompt, payload body, provider raw
response, local path, Source Locator, credential, token, secret, or storage
handle appears.
