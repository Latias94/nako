# FFR-030A PostgreSQL Job Backend Split

## Summary

- Split PostgreSQL job and job lease persistence out of `postgres.rs` into
  `postgres/jobs.rs`.
- Moved job SQL select fragments, `JobRepository`, `JobLeaseRepository`, job
  row mapping, lease duration validation, and stale lease error mapping into
  the new module.
- Kept managed artwork job transaction reuse explicit through
  `jobs::{insert_job_tx, get_job_tx}`.
- Left SQLite as the always-on backend and kept PostgreSQL contracts opt-in.

## Notes

`NAKO_TEST_POSTGRES_URL` was unset, so ignored PostgreSQL opt-in contracts were
not run. The next FFR-030 slice should either use the local PostgreSQL harness
when available or record the same opt-in skip explicitly.

Continue with FFR-030B by extracting another PostgreSQL repository family whose
SQL and row mapping can move together without creating a pass-through module.
