## Changes

- Added `postgres/addons_automation.rs`.
- Moved `AddonRepository` and `AutomationRepository` PostgreSQL
  implementations out of the broad `postgres.rs` backend.
- Moved addon registration, token, grant, routing plan, side-effect,
  automation provider, and automation artifact SQL select fragments into the
  new module.
- Moved addon/automation row mapping and generated artifact proposal hydration
  into the new module.
- Kept `set_addon_side_effect_apply_outcome_tx` as a `pub(super)` internal
  boundary because `MetadataRepository::commit_addon_metadata_write` still
  applies addon side-effect outcomes inside the metadata commit transaction.
