# FFR-020 Playback Runtime Split

## Summary

- Split playback staging policies into `staging_policy.rs`.
- Split playback selection helpers into `selection.rs`.
- Split transcode failure mapping and persisted failure updates into
  `failure.rs`.
- Split playback finished outbox event recording into `events.rs`.
- Split path helpers into `paths.rs`.
- Split HLS playlist and segment-name helpers into `playlist.rs`.
- Kept existing public and test-visible playback exports stable through
  `playback/mod.rs`.

## Validation

- `cargo check -p nako-server --tests`: passed.
- `cargo nextest run -p nako-server playback --no-fail-fast`: passed with 54
  tests run and 216 skipped.
- `cargo fmt --package nako-server`: completed.

## Notes

This was a behavior-preserving split. The remaining playback app service still
owns orchestration for direct play, remux, HLS, session lookup, cancellation,
support evidence, and runtime diagnostics. Future playback work can now split
those orchestration paths against smaller helper modules.

Continue with FFR-021 by choosing the next broad `nako-server::app` module.
