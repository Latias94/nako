# FFR-030E PostgreSQL Managed Artwork Backend Split

Date: 2026-05-23
Status: DONE

## Scope

- `crates/nako-db/src/postgres.rs`
- `crates/nako-db/src/postgres/managed_artwork.rs`
- `docs/workstreams/fearless-future-architecture-refactor/*`

## Changes

- Added `postgres/managed_artwork.rs`.
- Moved PostgreSQL `ArtworkTaskRepository`, `ArtworkCandidateRepository`, and
  `ManagedArtworkRepository` implementations out of the broad `postgres.rs`
  backend.
- Moved managed artwork SQL select fragments, row mapping, task queue,
  candidate intake, ingest lifecycle, managed artifact, selected artwork,
  gallery hydration, and cleanup lifecycle helpers into the new module.
- Kept `get_job_tx` and `insert_job_tx` as the explicit internal boundary to
  `postgres/jobs.rs` because managed artwork acceptance and processing update
  jobs inside the same PostgreSQL transaction.
