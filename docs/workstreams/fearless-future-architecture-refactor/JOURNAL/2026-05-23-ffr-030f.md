# FFR-030F PostgreSQL Import-State Backend Split

Date: 2026-05-23
Status: DONE

## Scope

- `crates/nako-db/src/postgres.rs`
- `crates/nako-db/src/postgres/import_state.rs`
- `docs/workstreams/fearless-future-architecture-refactor/*`

## Changes

- Added `postgres/import_state.rs`.
- Moved PostgreSQL `ManagedImportRepository`,
  `AcquisitionIntakeRepository`, and `NfoSidecarApplyRepository`
  implementations out of the broad `postgres.rs` backend.
- Moved managed import artifact, promotion apply, acquisition intake
  candidate, and NFO sidecar apply SQL select fragments into the new module.
- Moved import-state row mapping and source-kind codecs into the same module
  so SQL shape, state transitions, and decoding stay together.

- `postgres.rs` is now around 5,200 lines. It is smaller but still owns
  metadata/catalog graph persistence, library/media primitives, search,
  source duplicate, catalog governance, playback state, and transcode session
  persistence.
- FFR-030G should target metadata/catalog graph persistence next. That slice
  is larger and riskier than import-state because metadata commits and catalog
  graph replacement share transaction helpers and many row mappers.
