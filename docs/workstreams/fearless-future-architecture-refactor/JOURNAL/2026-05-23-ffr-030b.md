# FFR-030B PostgreSQL Event/Webhook Backend Split

## Summary

- Split PostgreSQL event outbox and webhook persistence out of `postgres.rs`
  into `postgres/events.rs`.
- Moved event and webhook SQL select fragments, `EventOutboxRepository`,
  `WebhookRepository`, event subject decoding, row mapping, and webhook
  delivery-attempt lookup into the new module.
- Left addon and automation persistence in `postgres.rs`; the wider
  event/addon/automation contract family remains the behavioral gate.
