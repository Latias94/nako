# FFR-040C API Admin Automation Surface Split

Date: 2026-05-23
Status: DONE

## Scope

- `crates/nako-api/src/admin.rs`
- `crates/nako-api/src/admin/automation.rs`
- `docs/workstreams/fearless-future-architecture-refactor/*`

## Changes

- Added `admin/automation.rs` and moved generated artifact proposal, review,
  acceptance plan, target, provenance, payload summary, and readiness DTOs out
  of `admin.rs`.
- The automation module now owns conversion from core generated artifact
  records into admin summaries, including raw prompt/payload redaction and
  metadata-authority boundary summaries.
- Kept the public `nako_api::admin::*` import shape stable through
  `pub use automation::*`.
- Moved the automation redaction tests into the new module so payload and
  prompt safety stays local to the admin automation API surface.

  `admin.rs`: managed artwork, playback, network, storage, and automation.
