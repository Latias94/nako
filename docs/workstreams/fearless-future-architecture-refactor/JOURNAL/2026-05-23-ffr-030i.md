# FFR-030I PostgreSQL Core Catalog Backend Split

Date: 2026-05-23
Status: DONE

## Scope

- `crates/nako-db/src/postgres.rs`
- `crates/nako-db/src/postgres/core_catalog.rs`
- `crates/nako-db/src/postgres/metadata_catalog.rs`
- `docs/workstreams/fearless-future-architecture-refactor/*`

## Changes

- Added `postgres/core_catalog.rs`.
- Moved PostgreSQL `LibraryRepository`, `LibraryItemRepository`,
  `MediaRepository`, `MediaProbeRepository`, `LocalInferenceRepository`,
  `IngestionFailureRepository`, `ScanRepository`, `SearchIndex`,
  `SourceDuplicateRepository`, and `CatalogGovernanceRepository`
  implementations out of the broad `postgres.rs` backend.
- Moved shared media item, media source, media probe, stream info, local
  inference, ingestion failure, scan snapshot, source duplicate, and catalog
  governance row mappers into the new module.
- Moved shared media/source/search transaction helpers and the core catalog
  codec family into the new module.
- Kept `postgres.rs` focused on connection, migration, schema validation,
  numeric conversion, row access, and module dispatch.
