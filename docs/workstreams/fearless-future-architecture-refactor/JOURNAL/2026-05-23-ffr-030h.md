## Changes

- Added `postgres/playback_runtime.rs`.
- Moved PostgreSQL `UserPlaybackStateRepository` and
  `TranscodeSessionRepository` implementations out of the broad
  `postgres.rs` backend.
- Moved user playback state and transcode session SQL select fragments, row
  mapping, transcode state/kind/failure codecs, cancellation, stale-session
  transition, and output-path transition logic into the new module.
- Removed the now-unused `PathBuf` import from `postgres.rs`.

## Judgment

- Continue FFR-030 before moving to FFR-040. After this split,
  `postgres.rs` is around 2,500 lines and still owns one cohesive backend
  family: library/media/probe, scan commit, search projection, local
  inference, ingestion failure, source duplicate, and catalog governance.
- The next task should extract that family into `postgres/core_catalog.rs`
  while leaving connection setup, migration, schema validation, generic row
  access, numeric conversion, and truly shared codecs in `postgres.rs`.
