# AWA-010 Scope And Evidence Freeze

Date: 2026-05-25

## Claim

Opened the Admin Web V2 Item Artwork Selection lane after GAR closeout.

## Scope

This lane is limited to item-scoped Managed Artwork gallery, Selected Artwork
select/replace, and Selected Artwork unpublish. Broader Managed Artwork
lifecycle, storage-drift remediation, provider search, uploads, catalog repair,
Generated Artifact review, NFO, settings mutation, users/permissions/Library
Access, and full-site i18n stay split.

## Initial Finding

Backend routes and HTTP docs already describe gallery/select/unpublish, but
the generated Admin Web contract lacks route constants and DTOs for this slice.
AWA-020 should audit that gap and define the exact AWA-030 contract work.
