# AWA-050 Confirmed Select And Unpublish Actions

Date: 2026-05-25

## Claim

The item artwork gallery now supports explicit select/replace and unpublish
confirmation flows with visible mutation failures and redaction-safe result
rendering.

## Changes

- Added `AdminDataSource.selectItemArtwork` and
  `AdminDataSource.unpublishItemArtwork` wrappers around the existing
  generated-route client methods.
- Mapped publish/unpublish Admin API responses into
  `ItemArtworkMutationResultSummary` and filtered result image URLs to
  first-party `/images/...` routes.
- Added guarded `Prepare -> Confirm` controls for selecting an artifact and
  unpublishing a current Selected Artwork slot.
- Rendered safe mutation outcomes for changed and idempotent-like results.
- Kept gallery fallback deterministic while allowing mutation failures to
  surface as visible route errors instead of mock success.
