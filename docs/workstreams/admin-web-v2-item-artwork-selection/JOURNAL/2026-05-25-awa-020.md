# AWA-020 Route/API Contract Readiness

Date: 2026-05-25

## Claim

Backend item artwork gallery/select/unpublish routes are ready for the first
Admin Web artwork slice. Generated Admin Web contract coverage is missing and
must be added before UI work.

## Findings

- In-scope routes:
  - `GET /admin/v1/items/{item_id}/artwork`
  - `POST /admin/v1/items/{item_id}/artwork/{kind}/select`
  - `DELETE /admin/v1/items/{item_id}/artwork/{kind}/selection`
- Supported image kinds are `poster`, `backdrop`, `logo`, `thumbnail`, and
  `banner`.
- Existing API/server tests cover gallery, select, and unpublish redaction
  against raw source URLs, token material, storage/cache/source URI fields,
  `managed-artwork://`, local paths, and `content_hash`.
- `apps/admin-web/src/adminApi/generated/contract.ts` and
  `crates/nako-api/src/admin_contract.rs` do not yet expose route constants or
  DTOs for item artwork.

## Decision

Proceed to AWA-030. Add generated route constants and TypeScript DTOs from the
Rust admin contract source, regenerate Admin Web contract output, then add
client bridge tests before any UI is built.
