# AWA-030 Generated Contract And API Bridge

Date: 2026-05-25

## Claim

Generated Admin Web contract coverage and explicit client bridge methods now
exist for item artwork gallery/select/unpublish.

## Changes

- Added `itemArtworkGallery`, `itemArtworkSelect`, and
  `itemArtworkSelection` route constants to `nako-api` Admin contract source.
- Added TypeScript DTOs for item artwork gallery, Managed Artwork summaries,
  Selected Artwork summaries, select request, publish/select response, and
  unpublish response.
- Regenerated `apps/admin-web/src/adminApi/generated/contract.ts`.
- Added `AdminApiClient.getItemArtworkGallery`,
  `AdminApiClient.selectItemArtwork`, and
  `AdminApiClient.unpublishItemArtwork`.
- Added a DELETE helper for Admin API calls.
- Added client tests proving encoded item IDs, generated paths, select request
  body, and unpublish DELETE behavior.
