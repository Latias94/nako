# 2026-05-26 - BPAT-010 Transport Decision

## Summary

Completed BPAT-010 by accepting short-lived browser playback tickets as the
first browser playback auth transport.

## Decision

ADR 0036 records the durable decision. The accepted model is:

- authenticated Public Client route issues scoped playback tickets;
- browser media URLs carry only opaque ticket material;
- direct stream, remux, HLS playlist, and HLS segments validate tickets before
  serving bytes;
- ticket values are treated as secrets and redacted everywhere;
- cookie/session auth and JavaScript HLS/MSE with headers remain later options,
  not the first transport.
