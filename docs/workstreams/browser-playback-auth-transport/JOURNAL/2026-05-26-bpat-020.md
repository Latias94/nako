# BPAT-020 Journal - Public Contract And SDK

Date: 2026-05-26

## Summary

Added the Public Client contract for issuing short-lived browser playback
ticket envelopes:

- protocol route inventory entry for
  `POST /sources/{source_id}/playback/browser-ticket`;
- protocol-owned request/response DTOs for browser playback ticket issuance;
- Public OpenAPI request/response schemas and boundary tests;
- TypeScript SDK `createBrowserPlaybackTicket` method;
- Rust client `create_browser_playback_ticket` method;
- refreshed generated TypeScript and Kotlin SDK package entries.

The contract returns browser-safe URL descriptors only. Actual ticket storage,
expiry, Library Access rechecks, Range handling, remux/HLS protection, and
redaction-safe server errors are BPAT-030.
