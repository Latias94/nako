# BPAT-050 Journal

Date: 2026-05-26

## Goal

Wire real Media Web player events to User Playback State writes without using
Admin API state or writing before playback actually starts.

## Changes

- Added watch-page playback event handlers for `play`, `playing`,
  `timeupdate`, `pause`, and `ended`.
- Added position-based throttling for normal progress writes. The first normal
  write requires at least 30 seconds of playback position, and later writes
  require at least another 30 seconds of position delta.
- Added pause flushing so short sessions can still save progress.
- Added end-of-play watched handling through the existing Public Client
  watched-state route.
- Kept progress payloads source-aware by sending the selected `source_id`.
