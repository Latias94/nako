# BPAT-030 Journal - Server Validation And Stream Use

Date: 2026-05-26

## Summary

Implemented server-side browser playback ticket issuance and validation:

- added an opaque in-memory `BrowserPlaybackTicketService` on `NakoApp`;
- stores hashed ticket lookup keys, not reversible claim payloads or raw token
  records;
- issues 6-hour source/mode/principal-scoped tickets from the Public Client
  route;
- validates ticketed direct stream, remux, HLS playlist, and HLS segment
  requests before serving bytes;
- appends the same scoped ticket to server-generated HLS segment URLs;
- rechecks current Library Access at ticket use;
- preserves Range behavior for direct/remux playback;
- limits auth middleware bypass to GET/HEAD media byte routes carrying a
  `ticket` query;
- keeps invalid-ticket client errors generic and redacts issued-ticket Debug
  output.

The implementation remains server-local and does not add a database migration.
Tickets expire on use-time validation and are cleared opportunistically when
new tickets are issued.
