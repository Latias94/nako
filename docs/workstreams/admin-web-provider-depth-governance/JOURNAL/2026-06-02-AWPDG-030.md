# AWPDG-030 Journal

Date: 2026-06-02
Task: `AWPDG-030`

## Summary

Added the explicit Admin API apply mutation for accepted durable Metadata
Candidate Reviews.

## Boundary

- The mutation calls `MetadataCandidateReviewApplicationService`.
- The request carries `item_id`, optional `expected_updated_at_ms`, and a
  required idempotency key.
- The response exposes apply/noop/conflict/replay facts and an idempotency key
  fingerprint, not the raw idempotency key.
- First apply writes only the root Provider Subject and accepted Provider
  Mapping.
- Preview related graph nodes remain evidence only and are not persisted as
  hierarchy state.
- Web UI, Public Client API, schema migrations, and related-node hierarchy
  application remain out of scope.
