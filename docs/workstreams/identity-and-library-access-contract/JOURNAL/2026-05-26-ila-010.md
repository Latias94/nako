# ILA-010 Journal - Domain And Baseline Schema

Date: 2026-05-26

## Changes

- Added `nako-core` identity/access domain records:
  - `UserId`
  - `User`
  - `UserStatus`
  - `UserRole`
  - `RoleAssignment`
  - `LibraryAccessLevel`
  - `LibraryAccessPolicy`
  - `EffectiveLibraryAccess`
- Added `IdentityAccessRepository` skeleton in `nako-core`.
- Generated a consolidated SQLite baseline at
  `crates/nako-db/migrations/baseline.sql`.
- Generated a consolidated PostgreSQL baseline at
  `crates/nako-db/migrations/postgres/baseline.sql`.
- Rewired SQLite and PostgreSQL migrators to register one baseline migration.
- Removed the old numbered SQLite/PostgreSQL migration files after baseline
  generation.
- Added SQLite baseline migration coverage and PostgreSQL baseline inventory
  coverage.

## Notes

- `UserPlaybackState` remains keyed by stable `principal_id`.
- The baseline intentionally does not add a foreign key from
  `user_playback_states.principal_id` to `users`. ILA-020 owns the bootstrap
  administrator and credential-to-user principal mapping.
- Baseline files keep source-file comments for auditability.
