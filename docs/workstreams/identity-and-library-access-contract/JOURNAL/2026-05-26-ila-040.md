# 2026-05-26 - ILA-040

slice.

- Added a small HTTP access gate that resolves effective Library Access from
  `AuthenticatedPrincipal` through `NakoApp`.
- Applied `browse` access to media-library and catalog browse routes,
  including item detail, item images, selected image bytes, facet item lists,
  source probes, and search results.
- Applied `play` access to playback decisions, direct streams, remux/HLS
  entrypoints, playback session lookup/cancel, and User Playback State writes.
- Applied `manage` access to legacy public library management commands that
  still exist outside `/admin/v1`.
- Preserved stable principal-scoped User Playback State storage while filtering
  Continue Watching by current effective Library Access.
- Kept Public Client DTOs unchanged; Admin policy rows, Role assignments,
  policy reasons, and credential/account internals are not exposed.
