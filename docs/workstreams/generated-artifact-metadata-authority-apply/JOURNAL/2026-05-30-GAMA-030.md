  `MetadataSuggestion` Generated Artifacts.

## Implementation Notes

- `AutomationAppService::apply_generated_artifact_metadata` rebuilds the apply
  plan, rejects non-executable plans, allows no-applicable-field replay as a
  structured no-op, resolves the current target again, and applies through
  `MetadataApplication`.
- `MetadataApplication` now accepts a lock scope. Generated Artifact apply uses
  all-lock protection; addon metadata writes keep source-relative lock
  protection.
- `MetadataApplicationPersistenceCommit` persists the updated `MediaItem` and
  catalog/search projection in one repository transaction for SQLite and
  PostgreSQL implementations.
