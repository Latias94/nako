# GAMA-010 - Lane Open And Boundary Audit

Date: 2026-05-29

Opened `generated-artifact-metadata-authority-apply` as the follow-on from the
Generated Artifact review mutation lane.

Findings:

- Review acceptance is intentionally not metadata apply.
- The current acceptance plan already exposes `StageMetadataAuthorityReview`,
  `MetadataAuthorityApplyRequired`, and `requires_metadata_authority_apply`.
- `AutomationApp::review_generated_artifact` only changes artifact review
  status.
- `MetadataApplication` is the right server-owned final apply module, but
  Generated Artifacts need a read-only apply-plan contract before mutation.
- NFO sidecar apply provides the strongest existing reference for accept/apply,
  stale checks, idempotent replay, field locks, and audit outcome shape.

Next task: `GAMA-020`, a no-mutation backend apply-plan contract for accepted
metadata Generated Artifacts.
