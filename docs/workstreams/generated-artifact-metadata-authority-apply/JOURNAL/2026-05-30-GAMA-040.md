# GAMA-040 Journal

Date: 2026-05-30

## Scope

- Added durable apply outcome persistence for accepted metadata Generated
  Artifacts.
- Added explicit idempotency-key request semantics for app-layer apply.
- Kept final Admin route, Web controls, bulk apply, and operations repair out
  of this slice.

## Implementation Notes

- `GeneratedArtifactMetadataApplyRequest` carries the `artifact_id` and
  `idempotency_key`; repeated use of the same key replays the persisted outcome.
- `generated_artifact_metadata_apply_outcomes` stores the redacted apply plan,
  outcome status, result flags, applied source, item reference, and failure
  reason.
- SQLite and PostgreSQL repositories commit an applied outcome in the same
  transaction as Canonical Metadata plus catalog/search projection updates.
- Failed non-executable plans persist a failed outcome without mutating the
  target item.
- The repo currently keeps direct baseline schemas for SQLite/PostgreSQL; this
  slice updates both baselines instead of adding historical replay migrations.
