# 2026-05-25 — NAH-020 Through NAH-050

Status: DONE

Implemented bounded in-memory provider attempt history in
`nako-notification-bridge`.

Key decisions:

- History is sidecar-owned and in-memory only.
- Default capacity is 20 and configurable through
  `NAKO_NOTIFICATION_BRIDGE_PROVIDER_ATTEMPT_HISTORY_CAPACITY`.
- Records contain only safe derived event/provider facts.
- Raw provider URLs, secrets, headers, message bodies, and raw event payload
  values are not stored.
- Nako core attempt schema and provider retry behavior remain unchanged.

Validation:

```powershell
cargo fmt --package nako-notification-bridge
cargo nextest run -p nako-notification-bridge attempt_history --no-fail-fast
cargo nextest run -p nako-notification-bridge --no-fail-fast
```

Result: passed.
