# ATRC-060

## Summary

Closed the Addon Task Runtime Contract lane.

## Notes

- The shipped contract covers host-owned Addon Task runs, sidecar-claimed
  execution, direct task-path dispatch, progress/result persistence, retry,
  cancellation, and safe failure classification.
- Authenticated outbound task dispatch credential management remains a
  follow-on because `AddonAuth::Bearer` and `AddonAuth::SharedSecret` need a
  real sidecar outbound secret source.
- Official-addon task-path smoke coverage remains a follow-on because the
  current published official metadata scraper smoke covers health and resource
  diagnostics, not task declarations.
- Source catalog / marketplace discovery, package signing, provider breadth,
  and process/container supervision remain separate lanes.
