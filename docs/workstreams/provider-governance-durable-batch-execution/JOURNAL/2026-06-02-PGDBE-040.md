# PGDBE-040 Journal

Date: 2026-06-02

## Summary

Added backend job-backed execution for queued durable Metadata Candidate Review
batches.

Implemented behavior:

- Candidate Review batch apply jobs execute through `DurableJobRuntime`.
- The Candidate Review batch apply resource class maps to the metadata shared
  runtime budget.
- Pending batch items call `MetadataCandidateReviewApplicationService::apply`.
- Applied/noop/skipped/blocked/stale/conflict/failed outcomes persist on batch
  items.
- Completed execution persists a terminal completed batch and succeeded job
  summary.
- Queued cancellation synchronizes the batch to cancelled instead of applying
  items.
