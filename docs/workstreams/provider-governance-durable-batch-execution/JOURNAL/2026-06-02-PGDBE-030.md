# PGDBE-030 Journal

Date: 2026-06-02

## Summary

Added the Admin create/status boundary for queued durable Metadata Candidate
Review batches.

Implemented behavior:

- `POST /admin/v1/metadata/candidate-reviews/batches` creates a queued durable
  batch from selected review IDs.
- `GET /admin/v1/metadata/candidate-reviews/batches/{batch_id}` returns the
  persisted batch status and redaction-safe item plan snapshots.
- create is idempotent by normalized idempotency key and persists a durable
  `MetadataCandidateReviewBatchApply` job with explicit batch input.
- create plans each item but does not execute Provider Mapping writes.
- generated Admin TypeScript contracts are synchronized.
