# Addon Source Catalog And Marketplace - Milestones

Status: Completed
Last updated: 2026-05-24

## M0 - Boundary Frozen

Status: Done 2026-05-24.

Exit criteria:

- the catalog problem is distinct from Addon Manager plan confirmation;
- source listing, discovery, and resolution are the first slice;
- package signing, provider breadth, and process supervision are explicit
  non-goals or follow-ons;
- the first executable task is identified.

## M1 - Catalog Model Frozen

Status: Done 2026-05-24.

Exit criteria:

- the first source catalog shape is documented;
- discoverable addon entries are represented as Nako-owned metadata;
- operator-facing resolution can be described without leaking secrets.

## M2 - Discovery Surface

Status: Done 2026-05-24.

Exit criteria:

- one addon source can be represented through a Nako-owned discovery surface;
- browse and resolution behavior are surfaced through Nako;
- catalog transitions are explicit and testable.

## M3 - Closeout

Status: Done 2026-05-24.

Exit criteria:

- fresh gates prove the catalog slice;
- docs describe the shipped discovery boundary;
- signing, provider breadth, and process supervision are split or deferred.
- rollback/update execution, authenticated outbound task-dispatch credentials,
  and official-addon task-path smoke coverage are split follow-ons.
