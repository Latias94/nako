# ASCM-020/030/060

## Summary

Implemented and closed the Addon Source Catalog And Marketplace lane.

## Notes

- Froze the first slice as read-only source listing, browse metadata, and
  descriptor resolution.
- Added a built-in `nako-official` source with the official metadata scraper
  catalog entry.
- Added Admin routes for source listing, entry browsing, and install candidate
  resolution.
- Resolution returns an `AddonInstallDescriptor` plus protocol install guide,
  reusing the existing install-guide boundary instead of introducing a new
  package or execution authority.
- The catalog does not register addons, create routing plans, create jobs,
  execute manager intent, download packages, sign packages, or supervise
  sidecars.
- Package signing, provider breadth, rollback/update execution, authenticated
  outbound task dispatch credentials, official-addon task-path smoke, and
  process/container supervision remain follow-ons.

## Validation

- `cargo nextest run -p nako-server admin_addon_source_catalog_browses_and_resolves_without_hidden_lifecycle_work --no-fail-fast`
- `cargo test -p nako-api admin_contract_includes_route_constants --no-default-features`
