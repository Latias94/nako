# Addon Source Catalog And Marketplace

Status: Active
Last updated: 2026-05-23

This workstream plans the source catalog and marketplace discovery layer after
the completed Addon Manager lifecycle lane. Nako now knows how to confirm
operator-owned install/update/remove intent; this lane decides how addon
sources are listed, resolved, and presented as installable catalog entries.

Package signing, provider breadth, and direct process/container supervision are
split follow-ons.
