## Decision

Recommended next lane: Metadata Provider Breadth.

Rationale:

- Packaging now makes Taru installable; metadata quality is the next immediate
  library value gap.
- The first slice can be narrow: provider capability registry, matching policy,
  raw response retention, and manual conflict confirmation.
- It builds directly on existing provider/NFO/catalog authority without adding
  unsafe acquisition or network traversal behavior.

Downloads should be split to `managed-import-staging` if prioritized. The safe
first slice is Taru-managed import staging for operator-provided URLs or
Addon-proposed artifacts: quarantine, validate, and promote manually. Torrent,
Usenet, and autonomous acquisition remain out of scope for that first slice.
