## Summary

Opened `hls-selected-main-audio-cleanup` as the follow-on to
`hls-audio-sidecar-artifacts`. The new lane focuses on removing selected audio
duplication from sidecar-capable multi-audio HLS main mux outputs while
preserving single-audio and no-sidecar behavior.

## Decisions

- Keep the lane limited to HLS output-shape cleanup.
- Keep FFmpeg CLI as the media engine boundary.
- Do not add language preference policy, codec-aware sidecars, LL-HLS, DASH,
  DRM/key delivery, or player-specific fallback negotiation in this lane.
- Start with characterization tests before changing command planning.
