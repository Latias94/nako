## Summary

HSMA-030 removed selected audio from sidecar-capable HLS main outputs.

## Changes

- Added `HlsArtifactManifest::main_output_has_audio()` to separate source audio
  presence from primary HLS output audio shape.
- Updated single-variant and adaptive FFmpeg HLS command planning to omit main
  audio maps and main audio encoder args when generated audio sidecars are
  present.
- Updated adaptive HLS `-var_stream_map` generation to use video-only variants
  when generated audio groups provide audio.
- Added `hls-main-output:v1;main_audio=false` to request variant identity for
  generated audio sidecar outputs.
- Updated server HLS tests to assert the new request identity component.
