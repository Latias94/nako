# Web Deferred Product Reentry Plan - Milestones

Status: Active
Last updated: 2026-05-28

## M0 - Open Lane

Exit criteria: deferred WBBP gaps have an explicit matrix and task ledger.
Completed by WDRP-010.

## M1 - Video-First Reentry

Exit criteria: the next Media Web implementation lane is opened or updated with
live Public Client and playback gates.

## M2 - Admin Operations Reentry

Exit criteria: downloads/acquisition and AI/automation reentry are routed to
Admin operations lanes instead of Media sidebar prototypes.

## M3 - User Media State

Exit criteria: playlists have either a backend contract lane or an explicit
deferred decision.

## M4 - Non-Video Media Domains

Exit criteria: photos, music, and podcasts have a domain-baseline decision that
references ADR-0021.

## M5 - Closeout

Exit criteria: all deferred product gaps are either assigned to follow-on lanes
or intentionally deferred with reentry conditions.
