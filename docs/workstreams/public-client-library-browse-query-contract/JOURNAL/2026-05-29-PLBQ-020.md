## Summary

Froze the first Public Client library browse/query contract:

- route: `GET /libraries/{library_id}/items`;
- query: `limit`, `offset`, `sort`, `order`, `facet`, and `watch_state`;
- response: `LibraryItemsResponse { library, items, page }`;
- access: effective `browse` required, inaccessible libraries return
  `404 not_found`;
- SDK expectation: `listLibraryItems(libraryId, query)`.

## Notes

`GET /items` remains the broad all-visible-items route. The first implementation
slice should not add a parallel `library_id` filter there.
