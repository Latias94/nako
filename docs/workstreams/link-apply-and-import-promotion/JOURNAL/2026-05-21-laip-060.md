# Link Apply And Import Promotion LAIP-060 — 2026-05-21

## Summary

Implemented post-storage partial-failure cleanup gates for Managed Import
promotion apply. A storage-created target followed by catalog commit failure no
longer leaves the apply in `committing_catalog` or marks anything promoted.

## Shipped

- Added VFS storage cleanup request/status/report types.
- Added default unsupported `StorageBackend::cleanup` behavior.
- Forwarded cleanup through cached and library-scoped storage backends.
- Added local cleanup for file and symlink targets with directory refusal,
  missing-target reporting, root-escape safety, security-violation no-mutation
  behavior, redacted reports, and directory sync after removal.
- Added server-side catalog failure injection for focused tests.
- On catalog commit failure after storage target creation, promotion apply now:
  - attempts storage cleanup through VFS only;
  - records `cleanup_complete` when cleanup succeeds or the target is already
    absent;
  - records `cleanup_pending` when cleanup is unsupported or fails;
  - keeps failed artifacts out of `promoted`;
  - replays cleanup terminal states without repeating storage mutation.
