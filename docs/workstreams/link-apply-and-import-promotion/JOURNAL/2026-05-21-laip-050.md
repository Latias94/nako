# Link Apply And Import Promotion LAIP-050 — 2026-05-21

## Summary

Implemented the first server-side promotion apply orchestration slice. This
slice turns an accepted Managed Import promotion into a Media Source only after
the target has been created through VFS storage apply.

## Shipped

- Added `ApplyManagedImportPromotionRequest`.
- Added `ManagedImportAppService::apply_promotion`.
- Revalidates accepted promotion facts against the current promotion plan before
  storage mutation.
- Executes copy/hardlink/symlink storage mutation through `StorageBackend::apply`
  only.
- Forwards `StorageBackend::apply` through `LibraryStorageBackend` so health and
  runtime boundary tracking cover apply operations.
- Records failed-before-mutation audit outcomes for stale plans, missing source
  artifacts, already-cataloged destinations, missing storage registry, backend
  resolution failure, backend apply errors, and typed non-applied VFS reports.
- Commits Media Item, Library Item state, Media Source, duplicate relationship
  suggestions, and artifact promoted state only after VFS reports a created
  target.
- Replays already-promoted apply records without repeating storage or catalog
  writes.
- Keeps move/delete source behavior and NFO sidecar mutation deferred.
