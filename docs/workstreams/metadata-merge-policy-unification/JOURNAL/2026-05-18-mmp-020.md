# 2026-05-18 - MMP-020 Characterization

## Summary

MMP-020 completed the characterization step before shared merge-policy movement.

Existing tests already covered:

- provider missing-only merge through `missing_only_merge_fills_empty_fields_without_replacing_existing_values`;
- provider full-refresh merge through `full_refresh_replaces_unlocked_existing_values`;
- NFO local-first import and lock writing through `nfo_service_discovers_and_imports_movie_sidecar_with_locks`;
- NFO remote-first missing-field behavior through
  `nfo_service_remote_first_import_only_fills_missing_fields_without_locks`;
- non-NFO locks blocking NFO import through
  `nfo_service_preserves_user_locked_fields_during_import`.

New tests added:

- `hierarchy_confirmation_allows_source_authority_to_refresh_own_locked_fields`
- `nfo_service_allows_nfo_authority_to_refresh_nfo_locked_fields`

These tests make the source-aware part of the policy explicit: a metadata source
may refresh fields locked by the same source, while locks from other sources
still protect their fields.

Passed:
