# 2026-05-18 - MMP-030 Shared Policy Boundary

## Summary

MMP-030 moved Canonical Metadata merge authority into `nako-core`.

Implemented:

- Added `crates/nako-core/src/media/merge.rs`.
- Exported the shared policy through `nako_core::media`.
- Removed `crates/nako-metadata/src/merge.rs`.
- Re-exported `MetadataMergePolicy` from `nako-metadata` so existing metadata
  callers keep using the same name.
- Updated hierarchy confirmation to use
  `MetadataMergePolicy::for_source_refresh_mode`.
- Updated NFO import to use `MetadataMergePolicy::for_nfo_import`.
- Replaced NFO's private populated-field helper with
  `populated_metadata_fields`.

Behavior preserved:

- Provider refresh still protects all locked fields.
- Hierarchy confirmation protects fields locked by other sources while allowing
  the current source to refresh its own locked fields.
- NFO import protects fields locked by non-NFO sources and allows NFO authority
  to refresh NFO-locked fields.
- NFO RemoteFirst still behaves as missing-only import.
