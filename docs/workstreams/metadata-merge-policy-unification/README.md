# Metadata Merge Policy Unification

Status: Proposed
Last updated: 2026-05-18

This workstream owns ARF-002 from the 2026-05-18 architecture review: NFO import
and provider refresh currently duplicate Canonical Metadata merge decisions.

The lane opens a focused execution path to put field authority, refresh mode,
and local metadata policy behind one shared merge-policy boundary. It does not
own NFO XML preservation, provider breadth, public API changes, or database
schema changes.
