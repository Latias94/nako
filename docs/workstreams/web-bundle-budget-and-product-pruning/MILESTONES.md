# Web Bundle Budget And Product Pruning - Milestones

Status: Queued
Last updated: 2026-05-28

## M0 - Activation

Exit criteria: WALW is complete.

## M1 - Budget Instrumentation

Exit criteria: bundle budgets are measurable and repeatable.

## M2 - Heavy Domain Pruning

Exit criteria: deferred domains are removed, quarantined, or lazy-loaded.

## M3 - Dependency Diet

Exit criteria: unused heavy dependencies are removed or justified.

## M4 - Final Frontend Closeout

Exit criteria: all six frontend lanes are complete or split with explicit follow-ons.
