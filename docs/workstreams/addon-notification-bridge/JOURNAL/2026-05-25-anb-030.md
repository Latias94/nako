# ANB-030 — Host Scheduler Proof

Status: DONE
Date: 2026-05-25

## What Changed

- Added official notification bridge facts to `nako-official-addon-catalog`.
- Added `nako.official.notification-bridge` to Nako's built-in official Addon
  catalog source.
- Added host tests proving catalog resolve, manifest registration, sidecar
  health-check, routing-plan sync, scheduled `library.scanned` delivery, and a
  redaction-safe succeeded delivery attempt through the existing Addon Event
  scheduler.
- Fixed `nako-notification-bridge` health responses and smoke expectations so
  `resource_count` matches its declared webhook resource.

## Notes

ANB-030 reused the existing Addon Event scheduler, routing-plan, delivery
attempt, and health-check paths. It did not add notification provider
credentials, provider API calls, message templates, provider-specific retry, or
new scheduler semantics to Nako core.
