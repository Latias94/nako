## Notes

The first red/green cycle exposed that current Addon manifest validation rejects
event-only manifests with `EmptyResources`. The ACK proof therefore declares a
narrow `webhook` resource on `/events/library-scanned` in addition to its event
subscription. This avoids a protocol change in ANB-020.

Provider fan-out remains intentionally unimplemented.
