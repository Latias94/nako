# ASD-030 Server-Backed Fixture Provider

Status: DONE
Date: 2026-05-18

## Scope

Implemented the first deterministic server-backed Android demo fixture
provider.

Changed:

- Added `apps/android/scripts/Start-DemoFixtureServer.ps1`.
- Updated Android fixture docs and README with the server-backed fixture
  command.
- Removed Android's required `ClientTranscodePlan.inputLocator` field because
  the Public Client API redacts `input_locator`.
- Added playback client regression coverage for transcode decisions without
  `input_locator`.

## Fixture Behavior

`Start-DemoFixtureServer.ps1`:

- prepares `apps/android/build/demo-fixtures/server-backed/`;
- generates `Night Harbor.mp4`;
- writes `Night Harbor.nfo`;
- writes a local `taru.toml`;
- runs `taru-server scan`;
- runs `taru-server import-nfo`;
- starts the loopback server unless `-PrepareOnly` is passed;
- can run `adb reverse` when `-AdbReverse` is passed.
