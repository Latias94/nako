# ASD-040 Android Media Smoke State

Date: 2026-05-18
Status: DONE

## Scope

Wire `Smoke-Emulator.ps1 -FixtureState profile-with-media` so Android can prove
the server-backed media path through Public Client API route shapes instead of
local fake media.

## Changes

- Added a debug-only `DebugSmokeFixtureSeedActivity` that writes one safe Server
  Profile through `SharedPreferencesServerProfileStore` and stores the token
  through `AndroidSecureTokenVault`.
- Added debug fixture seed unit coverage under `src/testDebug`.
- Extended `Smoke-Emulator.ps1` with `profile-with-media`, fixture server
  preparation/startup, `adb reverse`, profile/token seeding, Home/detail/source
  picker/player navigation, criteria files, and cleanup.
- Documented the state in `apps/android/SMOKE_FIXTURES.md` and
  `apps/android/README.md`.

## Evidence

  `apps\android\gradlew.bat -p apps\android :app:testDebugUnitTest --tests dev.nako.android.smoke.DebugSmokeFixtureSeedActivityTest --no-daemon`.
- `apps\android\gradlew.bat -p apps\android :app:assembleDebug --no-daemon`
  passed before the successful media smoke.
- `pwsh -NoProfile -File apps\android\scripts\Smoke-Emulator.ps1 -FixtureState profile-with-media`
  passed and produced:
  `apps/android/build/smoke/20260518-235008-profile-with-media-emulator-5554/`.
- Captured surfaces: `home`, `detail`, `source-picker`, and `player`, each with

## Notes

- The fixture writer is debug-only. Release builds must not expose app-state
  seed entry points.
- Generated screenshots, UI hierarchy dumps, server logs, and reports remain
  local evidence and are not tracked.
- The player evidence proves player-safe launch. CI device automation, golden
  image diffing, HLS/remux/session depth, and longer playback quality checks
  remain follow-ons.
