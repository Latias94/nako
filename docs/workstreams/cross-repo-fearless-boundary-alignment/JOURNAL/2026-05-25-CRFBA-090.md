# CRFBA-090 Contract Drift Hardening

Date: 2026-05-25

## Summary

Hardened the Addon Runtime contract surface touched by CRFBA-070 without
expanding into generated client publishing. `nako-addon-protocol` now owns an
explicit route inventory for the `/addon/v1/*` runtime paths. The reusable Nako
Runtime client and server runtime route registration use the same path
constants.

`nako-api` keeps its server-facing strongly typed DTOs, but now has parity
tests proving the serialized access-check and side-effect wire shapes match the
public protocol DTOs. Public Client OpenAPI tests also exclude every path from
the Addon Runtime route inventory instead of listing only individual examples.
