# CRFBA-070 Journal

Date: 2026-05-24
Owner: codex

## Summary

Aligned official addon protected-write host-client responsibilities with the
public addon protocol and client crates.

## Changes

- Added public protected-write permission, access-check, side-effect target,
  side-effect request, side-effect response, and typed metadata/artwork write
  request shapes to `crates/nako-addon-protocol`.
- Added `NakoRuntimeClient` to `crates/nako-addon-client` for access-check and
  side-effect submission over the Addon runtime HTTP surface.
- Kept runtime HTTP behavior in `nako-addon-client`, not in
  `nako-addon-protocol`.
- Added client behavior coverage for bearer token header placement, token-body
  leak rejection, safe HTTP error mapping, metadata/artwork side-effect payload
  shaping, retryability, and version-tolerant response parsing.
- Fixed the reusable reqwest transport error mapper to strip request URLs and
  cap error text before exposing `AddonClientError::Http`.
- Changed the official metadata scraper `nako_runtime` module into a thin
  facade over `nako-addon-client` and `nako-addon-protocol` instead of keeping a
  duplicate transport/request/response/error implementation.

## Concerns
