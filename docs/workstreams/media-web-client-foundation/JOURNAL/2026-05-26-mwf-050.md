# 2026-05-26 - MWF-050 Source Selection And Playback Shell

## Summary

Implemented the MWF-050 Media Web source/playback slice inside the shared
`apps/admin-web` frontend.

## Changes

- Added URL-owned `source_id` state for Media Item detail and
  `/media/watch/:itemId`.
- Added Source/Version Picker UI from `ItemDetailResponse.sources`.
- Added playback decision preview through the generated Public Client SDK.
- Added a safe watch shell that does not render a browser stream URL or fake
  media element while playback auth transport remains unresolved.
- Added User Playback State reads plus watched/unwatched writes through
  `/users/me/playback-state`.
- Extended fixture data with a second source version and deterministic playback
  decision/state responses.
- Added focused Media Web and data-source tests covering route URLs, SDK route
  usage, redaction, watch shell behavior, and watched-state writes.

## Notes

MWF-050 is done with a named concern: real browser playback is still gated on
MWF-GAP-004. The follow-on must choose JavaScript HLS/MSE with headers,
cookie/session playback auth, or short-lived playback tickets before Media Web
renders a real media element.
