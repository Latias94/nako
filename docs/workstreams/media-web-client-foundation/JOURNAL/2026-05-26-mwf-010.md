# 2026-05-26 - MWF-010 Scope Split

Opened `media-web-client-foundation` from the client-surface planning lane.

Decisions:

- Media Web is the first-party browser playback client.
- Admin Web remains the operator console and should not become the watch-first
  player.
- Media Web consumes Public Client API contracts only.
- The first slice is local-media-first and excludes recommendations,
  storefront-style discovery, public registration, Tauri packaging, and native
  playback integration.
- MWF-020 must audit Public Client API/OpenAPI/SDK readiness before UI
  scaffolding.
