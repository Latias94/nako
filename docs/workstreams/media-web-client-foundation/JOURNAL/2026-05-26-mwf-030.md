# MWF-030 - Shared Media Surface Foundation

Date: 2026-05-26
Status: DONE

## Work Completed

- Kept Media Web inside the existing `apps/admin-web` frontend package instead
  of creating a separate package.
- Added explicit Admin and Media route surfaces:
  - Admin routes keep the existing `/overview`, `/libraries`, `/settings`, and
    related namespaces.
  - Media routes live under `/media/*`.
- Added symmetric Admin/Media surface switchers so operators can move between
  viewer and management contexts without losing the product boundary.
- Added a Media session provider with in-memory live connection state and an
  explicit fixture mode.
- Added a Media data-source boundary backed by the generated Public Client
  TypeScript SDK for live mode and deterministic fixtures for development.
- Added first Media pages for connect, home, libraries, and search using
  accepted Public Client API contracts only.
- Updated Access route tests to assert the current identity/access state:
  backend edit contracts exist, while Admin Web account mutation controls remain
  hidden until credential/login/lockout UX is accepted.
