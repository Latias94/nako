# PBSI-020 Session Journal

Date: 2026-05-29
Task: PBSI-020

## Summary

Froze the Public Client browser playback session identity contract:

- `BrowserPlaybackTicketResponse.playback_session_id` becomes a required
  nullable public field;
- `direct`, `remux`, and `hls` ticket responses return non-null playback
  session ids;
- `subtitle` ticket responses return `null`;
- non-subtitle opaque browser tickets bind server-side to the same durable
  playback session exposed in JSON;
- browser heartbeat uses `POST /playback/sessions/{session_id}/heartbeat` with
  the authenticated owner principal.

## Notes

Current implementation creates playback sessions at media request time and also
exposes `x-nako-playback-session-id` on binary responses. PBSI-030 must move
browser-ticket media modes to pre-created, ticket-bound sessions so web clients
can heartbeat without parsing media URLs or response headers.
