## Closeout Decision

PBSI is complete. The lane target state is met:

- browser ticket JSON exposes a stable control-plane
  `playback_session_id`;
- direct, remux, and HLS browser tickets allocate non-null playback sessions;
- subtitle tickets remain sessionless with `playback_session_id: null`;
- ticketed media requests attach to the same server-side playback session;
- heartbeat authority is `POST /playback/sessions/{session_id}/heartbeat`
  with the authenticated Public Client principal;
- media URLs remain token-safe and are not the heartbeat identity source;
- TypeScript/Rust SDKs expose the accepted response shape;
- `web/` sends heartbeat through the explicit playback session id.
