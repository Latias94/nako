# PRRS-040 Journal — Admin Runtime Pressure Diagnostics

Date: 2026-05-29

## Summary

PRRS-040 surfaced playback resource pressure in Admin runtime diagnostics. The
new `resource_pressure` field reports resource class, enforcement mode,
configured capacity, available permits, and in-use permits without exposing raw
paths, locators, command lines, or media filenames.

The proof uses a running HLS session to show CPU transcode permit pressure
through `/admin/v1/playback/runtime`. Admin TypeScript contracts were refreshed
for both web surfaces because the Admin DTO shape changed.
