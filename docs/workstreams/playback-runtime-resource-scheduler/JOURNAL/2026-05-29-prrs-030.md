# PRRS-030 Journal — HLS And Remux Permit Enforcement

Date: 2026-05-29

## Summary

PRRS-030 wired the server-owned playback runtime admission model into the HLS
and remux process-backed start paths. New starts acquire host-owned permits
before launching runtime work, and browser playback preflight routes transfer a
pre-acquired permit into the spawned background task so route returns do not
release capacity early.

Existing active or completed session reuse stays permit-free, which preserves
the current reuse contract and avoids double-acquiring capacity for already
running work.
