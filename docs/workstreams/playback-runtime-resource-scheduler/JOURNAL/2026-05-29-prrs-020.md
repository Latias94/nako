# PRRS-020 — Playback Resource Demand And Admission Model

Status: DONE
Date: 2026-05-29

## Summary

Added the first server-owned playback resource model in
`crates/nako-server/src/app/playback/resource.rs`.

The model currently covers:

- direct remote stream demand;
- remux process demand;
- HLS CPU/GPU transcode demand;
- remote input staging demand;
- HLS artifact I/O demand.

Admission decisions can now report accepted, rejected, and not-yet-enforced
resource classes. PRRS-020 intentionally does not enforce route behavior yet;
HLS/remux permit acquisition remains PRRS-030.

## Validation

```text
cargo nextest run -p nako-server playback_resource --no-fail-fast
cargo nextest run -p nako-server playback --no-fail-fast
```

Both gates passed locally.

## Follow-Up

PRRS-030 should wire the admission boundary into HLS and remux start paths and
tie permit lifetime to the actual process-backed runtime work.
