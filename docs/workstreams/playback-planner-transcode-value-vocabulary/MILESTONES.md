# Milestones

## M1 - Lane Opened

Exit criteria:

- Workstream docs exist.
- The first executable task has clear scope and gates.
- The lane is linked from playback architecture indexes.

## M2 - Playback Planner Vocabulary Owns Its Values

Exit criteria:

- `nako-playback` has no direct `nako-transcode` dependency.
- Planner public records use playback-owned value types.
- Server adapters map playback values to transcode execution values.
- Playback planner and server playback gates pass.

## M3 - Lane Closed

Exit criteria:

- Evidence includes dependency-tree, nextest, fmt, and diff checks.
- Closeout records any remaining playback/transcode boundary work.
