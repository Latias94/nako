# PGR-100 — Safe Database Backend Diagnostics

Date: 2026-05-20
Status: complete

## Goal

Add safe database backend diagnostics to the Admin system config route and
document explicit SQLite/PostgreSQL backend-selection behavior without leaking
database credentials, local paths, URLs, or raw database errors.

## Changes

- Added Admin DTO fields for a database diagnostics block.
- Reported configured backend kind, active backend kind, URL scheme,
  runtime-support status, startup migration status, and backend capability
  booleans.
- Kept the active `NakoDatabase` available through app composition for
  diagnostics without exposing concrete SQLite/PostgreSQL adapters.
- Added `ServerStartupReport.database_migrated`.
- Updated the Admin TypeScript contract and generated Admin Web contract.
- Extended system config tests to assert database diagnostics and redaction.
- Updated HTTP API documentation for the new safe database diagnostics block.
